# 任务  
严格按照下方要求为我生成一张影视级道具设计图

# 道具  
1. 道具描述：  
真实质感，精密工业美学。一辆充满未来主义气息的定制版赛博复古巡航摩托车，车身主体采用液态金属般的电镀钛色，在光线下流转出蓝紫渐变冷光。油箱与挡泥板覆以手工敲打的锤纹黄铜饰面，并以激光蚀刻出精细的电路图腾纹样。低矮修长的车身线条极具攻击性，裸露的编织车架如肌肉纤维般有力，V型双缸引擎被抛光成镜面，散热鳍片间透出幽微的琥珀色内构光。皮质鞍座为手工缝制焦糖色马鞍革，随时间推移产生独特使用痕迹，圆灯复古头灯外圈由LED光刃环绕。轮毂为细辐条空心结构，内嵌红色阻尼光环。整车呈现出“精密机械的温度感”，在粗野力量与极致优雅之间取得微妙平衡，设计语言兼具西海岸混搭风格与东方侘寂美学，适合作为电影主角的标志性座驾。处于莫兰迪配色场景中，工业美学风格，侧逆光，轮胎扬起细微尘雾，环境光在金属曲面上游走，随机动态角度拍摄，氛围孤高且充满故事感，细腻材质渲染，独一无二的存在感。

2. 画面风格  
电影级光影，真实金属与皮革纹理，白色无干扰背景，电影级布光，超高细节，统一色彩系统，高信息密度排版，真实质感

# 画面要求  
## 画面布局  
1. 左侧：高质量道具主视觉半身（约3/4前侧角度），呈现摩托车最具辨识度的前部与侧面轮廓，展现材质质感与光影层次  
2. 右侧：模块化道具信息系统，采用大量细边框分割，具体模块化信息如下：  
- 标准多角度展示图（正视图、侧视图、后视图、顶视图），比例统一，标准化线图风格  
- 核心部件细节特写（头灯及仪表、引擎缸体及散热片、制动卡钳与碟盘、定制轮毂与轮胎纹理）  
- 涂装与材质设计说明（色彩配方示意、锤纹黄铜、电镀钛色渐变流程、皮革染色工艺）  
- 车身结构与人体工学设计（座高、把距、脚踏位置几何示意）  
- 标志性部件分解展示（油箱蚀刻图腾、车架编织结构、排气管异形消音器）  
- 姿态与场景参考（静态陈列、弯道压倾角、荒漠直线巡航）  
- 细节氛围感参考（启动时内构光效、金属反光板局部、尘土附着感）

# 画面整体要求  
白色无干扰背景，统一UI风格，文字区域规整，所有模块视觉统一，以高精渲染或极致设计稿形式呈现，呈现出和电影前期设定档案同级的完成度。
