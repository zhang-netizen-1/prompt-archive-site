# 任务
严格按照下方要求为我生成一张影视角色人物版

# 人物
1. 人物描述：
- 真人，真实质感。美人，服装精致繁复有设计感柔软面料，广袖魏晋交领长裙绣金金配色，发饰，两鬓有发饰，整体发型雅致有特点，锁骨，流苏古典项链，妩媚天真而不自知，一位19岁的东方美女，黑长直发散落于肩头两侧且几缕发丝拂面，发丝呈现自然蓬松感与垂坠感，身材娇小，皮肤白皙如陶瓷般水嫩且偏冷白皮，有着网感脸和随机妆容、饰品，体呈现纯欲风、偶像气质、甜美氛围的高颜值网红，处于莫兰迪配色场景中，甜美少女系风格，侧光，发丝轻飘凌乱，随机角度拍摄，氛围慵懒俏皮，细腻笔触，独特韵味的美
2. 画面风格
电影级光影，真实皮肤纹理，白色无干扰背景，电影级灯光，超高细节，统一色彩系统，高信息密度排版，真实质感

# 画面要求
## 画面布局
1. 左侧：高质量角色主视觉半身肖像
2. 右侧：模块化角色信息系统，采用大量细边框分割，具体模块化信息如下：
- 全身三视图（正面、侧面、背面），其中角色比例统一，三视图标准化
- 角色身份资料
- 面部五官细节特写
- 妆容设计说明
- 发型设计
- 服装结构设计
- 配饰细节展示
- 表情参考（开心、欢笑、愤怒、悲伤）
- 动作参考（站立、转身、撑伞）
- 场景氛围推荐

# 画面整体要求
白色无干扰背景，统一UI风格，文字区域规整，所有模块视觉统一
