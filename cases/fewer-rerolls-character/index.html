# 角色版

## 任务
严格按照下方要求为我生成一张3D国漫风格影视角色人物版。

## 人物
1. 人物描述：
- 3D国漫渲染风格，皮肤带有细腻的次表面散射。一位使用流星锤的少女，双马尾造型，身着红色劲装，裙摆高开衩露腿，古装侠女风范。美人，服装精致繁复有设计感，柔软面料与皮质护具结合，交领束腰设计，金红配色刺绣暗纹，发饰点缀两侧，整体发型利落飒爽且富有动感，锁骨处有简约皮质护颈或流苏古典项饰。东方少女，双马尾高高束起垂落肩头，几缕碎发拂面，发丝呈现自然蓬松感与动态飘逸感，身材娇小但身形矫健随机战斗妆容与饰品，整体呈现飒爽甜酷风、武侠偶像气质、兼具甜美氛围与凌厉感。处于干净富有空气感的简洁场景中，流星锤锁链缠绕于身侧，侧光照明，发丝与披帛轻飘，动态随机角度拍摄，氛围慵懒俏皮下隐藏战意，3D渲染细腻笔触，独特韵味的美。

2. 画面风格
电影级3D灯光，PBR真实皮肤纹理渲染，白色无干扰背景，影棚级多光源布光，超高细节，统一色彩系统，高信息密度排版，3D国漫质感。

## 画面要求
### 画面布局
1. 左侧：高质量角色主视觉半身肖像
2. 右侧：模块化角色信息系统，采用大量细边框分割，具体模块化信息如下：
- 全身三视图（正面、侧面、背面），其中角色比例统一，三视图标准化，展示流星锤的背挂与手持状态
- 角色身份资料
- 面部五官细节特写
- 妆容设计说明
- 发型设计（侧重双马尾结构与动感）
- 服装结构设计（侧重红色劲装结构、开衩裙摆与护甲分解）
- 配饰细节展示（包含流星锤武器解析）
- 表情参考（开心、欢笑、愤怒、悲伤）
- 动作参考（站立、转身、流星锤挥舞）
- 场景氛围推荐

## 画面整体要求
白色无干扰背景，统一UI设计风格，文字区域规整，所有模块视觉统一。
