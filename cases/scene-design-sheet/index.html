# 任务 
请帮我生成{{[3D国漫]}}的{{[古代小院子]}}的场景设定图: 
1. 场景描述如下 - {{[古风]}} 
2. 该场景设定图需包含下方模块，同时所有模块无重叠、无裁切、布局清晰规范： 
- 场景分区细节组：同一完整场景内的核心功能分区，每个分区的无多余杂物正视图、正侧视图，完整呈现分区内的结构、陈设、布局，所有分区视图的空间比例、材质、光影、风格100%统一，完全正交无透视畸变 
- 全局场景正交转面组：同一完整场景的正面视图、前45度轴测视图、正侧面视图、后45度轴测视图、背面视图、俯视顶视图，共6个全局视图，全部等宽等高规范排布，统一场景结构、统一陈设布局、统一光影、统一空间比例，完全正交无透视畸变，场景完整边界全部入镜，无任何结构裁切
- 补充视角氛围组：同一完整场景的人视主视角、半鸟瞰视角、仰视空间视角，以及同一场景的固定时段光影氛围视图（如清晨、黄昏、夜间），场景结构、陈设、比例与全局主视图100%完全统一，无任何结构差异 
- 材质细节特写组：场景内核心陈设、建筑构件、地面墙面、植被装饰、面料织物等关键部位的超近距离特写，清晰展示材质纹理、质感、肌理、光影反射等细节
 - 全图所有模块的同一场景，空间结构、陈设布局、材质质感、光影氛围、色彩风格100%完全一致，无任何差异，画面比例16:9，高精度，细节拉满，符合影视级动画/游戏场景设定标准 
 # 要求： 
 场景设定图具体要求如下： 
 - 影视级场景设定全览表，影视级场景正交转面参考图，{{[图片风格，记得和第一个变量保持一致，例如3D CG动画风格，OC渲染，PBR物理级材质，次世代高精度场景资产]}}，8K超高清，超精细细节，全局统一柔和漫射光照，无强烈明暗对比，无阴影遮挡核心结构，纯净浅灰色或白色背景，无任何多余场景、无关道具、杂物、特效、人物元素 
 # 注意： 
 全程无过度硬朗的工业/军事风尖锐轮廓，无杂乱冗余元素，所有模块严格遵循正交无透视规则，无结构错乱、比例失调问题
