01 提示词原文

# 任务
1. 请帮我根据下方故事，生成一张手绘风格分镜稿，苏晚清 @@图片1 ，顾霆琛 @@图片2 
2. 该手绘风格分镜稿使用3X2的布局模式，每行3张，共2行，使用脸部留白带十字定位辅助线效
# 要求 
1. 铅笔单线条线稿（脸部留白带十字定位辅助线）风格，不追求精细光影和色彩，重点突出角色动作与镜头节奏,请注意，侧面、半侧面的人脸也要使用脸部留白带十字定位辅助线的风格，请勿展示人物五官
2. 每个镜头都标注镜头类型（如低角度、极端广角、手持近景）、表演提示、音效说明 
3. 画面中需用不同颜色的箭头来标注引导线： 
- 红色：机位运动箭头 / 构图箭头，标注摄像机的运动轨迹、拍摄角度和构图变化 
- 蓝色：角色动作轨迹箭头，指示角色 / 物体的移动路线、肢体运动方向和幅度 
- 绿色：互动关系箭头，标注射击、投掷、攻击等物体的飞行轨迹，以及角色间的互动方向 
- 橙色：效果 / 冲击力箭头，指示爆炸、碰撞、命中点的受力方向和影响范围 
- 紫色：音效 / 标注引导箭头，指向需要添加音效、文字说明或特效备注的位置 
4. 上述12个镜头完整串联起一场职场相遇的完整桥段，通过镜头切换和动作衔接构建出流畅的动作逻辑。 
# 故事内容如下： 
0.0-1.5s，全景，跟镜，白天，现代公司走廊，落地窗洒入阳光，苏晚清，面向镜头，怀抱文件夹快步小跑，神情焦急，高跟鞋急促敲击地面，苏晚清在画面中央，快步小跑，神色慌张[急促的脚步声，纸张摩擦声] 1.5-2.5s，中景，推镜，白天，公司走廊转角，顾霆琛，背对镜头，从转角出；苏晚清，面朝顾霆琛，撞入他怀中，文件脱手飞散空中，苏晚清撞向顾霆琛，表情惊愕；顾霆琛侧身，下意识抬手[碰撞闷响，纸张哗啦散落] 2.5-4.0s，近景，推镜，白天，公司走廊，散落一地的白色文件，苏晚清，面向镜头，后退半步，看着满地文件，慌乱开口，发丝垂落脸颊，苏晚清在画面中央，低头又抬起，眼神慌张，嘴唇轻启[略显急促的呼吸声，苏晚清:对不起，顾总] 4.0-5.5s，特写，低仰角贴脸渐进推进+收尾180°小半环绕运镜 → 主体发力点锚点锁焦，白天，公司走廊地面，散落的文件与光斑，苏晚清的手，伸向地面文件；顾霆琛的手，从右侧疾入，一把握住她的手腕，骨节分明，苏晚清的手悬在文件上方，被猝然握住，手指微蜷；顾霆琛的手强势而克制[衣料摩擦声，轻微的吸气声] 5.5-7.0s，近景，固定运镜，白天，公司走廊，两人笼罩在暧昧的逆光中，苏晚清，半蹲在画面左侧，抬头面向右侧的顾霆琛；顾霆琛，立于右侧，俯身面向苏晚清，握着<!--xmv272 -->她的手腕，目光深邃低语，苏晚清仰头，眼眶微红，呼吸停滞；顾霆琛眼神暗涌，带着不容拒绝的意味[心跳声渐强，背景安静，顾霆琛:等等] 7.0-8.0s，特写，固定运镜，白天，公司走廊，两人面孔交叠的浅景深，苏晚清眼眸颤动，倒映顾霆琛；顾霆琛唇角微扬，神情复杂，拇指轻抚她腕间，苏晚清在画面左侧，眼神躲闪又留恋；顾霆琛在右侧，视线灼热，似笑非笑[呼吸声缠绕，钟表滴答声]
