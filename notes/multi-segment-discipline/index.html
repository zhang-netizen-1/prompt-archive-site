多段成片的分段纪律与连续性

方法视频源资料：多段成片的分段纪律与连续性（visual-prompt-system）

多段成片的分段纪律：段间切点、转场三法与全片光线轴的处理规则。

目录

〇、工作流：分镜头脚本 → 撰写提示词 → 分段（三步，顺序不可颠倒）一、第一原则：段是「连续段落」，不是「独立短片」二、写作顺序：先一条时间轴，最后才切三、段内只有"接着上一镜往下"四、场景不变时，光线也不能推进五、连带的三条硬规则（同一案例得出）六、验收清单（交付前逐条过）七、对白长度：一镜到底按「最长一次连续说话」算，不按总时长算八、审片清单：镜头语言层面最常犯的六类问题九、沉默怎么拍：在跟拍镜里沉默，不要切空镜十、对话驱动型短片：每一镜都在对话的节奏里十一、转场：只用三种，而且声音不断十二、规范写在哪儿：工作文件里，不进生成文件十三、相关

适用：任何"一次生成装不下、必须分段生成再拼接"的成片（对话走场、叙事短片、MV 等）。 来源：2026-09-17 案例《一天四十三次日落》三轮实测迭代与志光逐条纠正（原话保留在第四节与第六节）。

〇、工作流：分镜头脚本 → 撰写提示词 → 分段（三步，顺序不可颠倒）

志光 2026-09-17 定："下一次长一点的视频，就应该先出分镜头脚本-撰写提示词-分段。"

  1. 先出分镜头脚本：故事 → 一张分镜表（镜号｜时长｜景别／机位／运镜｜画面内容｜台词｜声音），全片一条连续时间轴。这一阶段只定内容与节奏，不写提示词（方法见 拆解分镜规则）。
  2. 再撰写提示词：按 模板-视频提示词总结构 把分镜表逐镜写成「镜头 ＋ 拍摄内容」，全片仍是一份文件（总稿）、一条时间轴。
  3. 最后才分段：按单次生成长度上限在镜头边界切，段内时间轴归零，正文一字不改。任何修改都回到第 1／2 步改总稿，再重新切。

禁止倒着做（先分头写每段的提示词）：那样每一段都会自动长出建立镜与收尾镜——这正是本案例连续三版犯的错。

一、第一原则：段是「连续段落」，不是「独立短片」

分段的原因只有一个——生成工具不能一次出无限长。段与段之间只该有切点，不该有起承转合。

  • 不要给每一段配"建立镜（空镜）"与"收尾镜（走远／抒情／定格）"：同一场景、连续时间里，这两类镜头在拼接时是废镜（必被裁掉），还会让观众读成"又到新地方了""每段又结一次尾"。
  • 全片只在第一段开头建立一次、最后一段结尾收束一次；中间各段直接以动作或对白开场、以动作收场。
  • 警惕那个看起来专业的模板：「空镜建立 → 对白主镜 → 插入镜 → 情绪收束」。把它套到每一段上，就是把段当成了独立小片——本案例 v1／v2／v3 连犯三次。

二、写作顺序：先一条时间轴，最后才切

  • 正确写法：先写「总稿」——一条连续时间轴、镜头从头排到尾，只有一个全局设定、一份参考图；确认后再机械切割成生成稿：切点只落在镜头边界，段内时间轴归零，正文一字不改。
  • 反例：按"第 N 段"分头写，每段各自配全局设定与情绪弧线——结构上必然长出冗余镜头。
  • 改动只改总稿，再重新切；生成稿不手改。交付前校验：总稿镜数 = 各段镜数之和、正文逐字一致。

三、段内只有"接着上一镜往下"

  • 每段（第一段除外）首镜加一句承接描述（上镜末态复述）——体系内 范例-盛唐分镜提示词-1至14镜全量 的"前一个分镜描述"就是同一机制。
  • 段内镜头收尾一律是"继续往前"的动作，不抒情、不定格（除全片最后一段）。
  • 不在段内写任何"这是开头／这是结局"的定位句。

四、场景不变时，光线也不能推进

同一场景的 70 秒对话里，背景光色如果从傍晚走到日落，观众会算出"其实过了很久"，与"只聊了几句"自相矛盾——志光原话："假设我现在正在跟你聊，聊了 1 分钟，然后背景里面各种光色在变，会让看的人觉得在这 70 秒里面你们只是对了几句话，然后背景就变化那么大，其实是不真实的。"

判据：逐个镜头问一句"这一镜是否让观众以为时间过去了"，是就删。

五、连带的三条硬规则（同一案例得出）

  1. 身高差悬殊时不要要求"两人全身同框"：模型为同时满足画幅与身高差，会把他"抬起来"（抱起／背负／攀爬在身上）——实测原话"中间小王子爬在女生身上了"。做法：以他的视高取景，或只取她的局部；锚定里写硬约束（始终双脚站地、头顶高度、不得被抱起/背负/攀爬/坐在她身上）。
  2. 肢体动作写在台词之前（起势）与之后（收势），不要拴在台词的字上、更不要复述台词里的词——官方口径明确"切勿在每句话中插入表演提示打断语流"，被复述的词也可能被当成台词再念一遍。
  3. 情绪镜常态为主、一闪而过：单镜 0.8–1 秒、每镜只给一个微变化，避免"导演替角色演情绪"的刻意感。

六、验收清单（交付前逐条过）

  • 全片只有一处建立镜、一处收束镜
  • 每段直接以动作／对白开场，段内没有空镜式过场
  • 总稿与生成稿正文逐字一致（总稿镜数 = 各段镜数之和）
  • 段间没有光线／时间推进
  • 每段（除第一段）有承接描述
  • 台词按语速核算（4 字/秒），口型镜只给"停下来说话"的镜
  • 相邻两镜景别不重复；段与段之间的镜头处理不雷同

七、对白长度：一镜到底按「最长一次连续说话」算，不按总时长算

  • 一镜到底（连续时空、不换场景、人一直在走）会把说话时间全额计费：观众感受到的是真实经过的时间，没有剪辑给的"跳时间"红利——所以这类片子的说话密度应该低于快切片（舒适区约 50–60%，快切片可以到 70% 以上）。
  • 判断"对白是否太长"的指标不是台词总时长，而是单镜最长的一次连续说话：超过 4–5 秒就要拆（拆台词 ＋ 中间插一个不说话的动作/插入镜）。
  • 台词一句不删也能把"话多"的感觉降下来，三个手法：① 拆长句——把 >4 秒的一镜一分为二，中间给 0.8–1 秒的插入镜；② 每个问答之后给 1–1.5 秒"只走路不说话"的呼吸点；③ 镜头永远跟着人走，不做远处的固定机位观察（否则读起来像另外架了一台机器，"一镜到底"就破了）。
  • 反例（不要做）：删掉"不说话"的镜头来压缩时长——那会让说话密度升高，越剪越像话多。

案例数据（《一天四十三次日落》v4→v5）：台词 157 字全部保留，纯说话 39 秒；总长 60.0→67.4 秒（增量全是走路），说话密度 67%→58%，最长连续说话镜 6.2→4.4 秒。

八、审片清单：镜头语言层面最常犯的六类问题

按"专业导演审片"的顺序逐镜过一遍，比看整体结构更容易抓出真问题：

  1. 光向必须能由机位与太阳方位推导。写"逆光"之前先问：机位在人前还是人后？人朝哪边走、太阳在哪边？——人在落日方向行走时，机位在正前方＝顺光，写"逆光"就是几何错误（本案例连续三次把机位从侧后改回正前，逆光声明跟着错）。最好在【光线设计】里把推导规则写死，逐镜遵守。
  2. 轴线与屏幕方向要定死。侧向／侧后镜必须写明取哪一侧、人在画面里朝哪个方向走，否则生成端各镜随机，拼接起来就是越轴。
  3. 同一功能的镜头不要用同一台机器。五句台词若都用"同高度＋同速后退跟拍"，成片就是同一镜重复五遍——按功能分型：随行近景／过肩／长焦侧向／低角度仰拍／背面越肩／广角贴身。
  4. 情绪镜用身体代替脸。四次"特写她的眼睛"一定刻意；换成眼睛／侧脸（碎发）／手（提包带）／脚步（步子错开半步），情绪反而更真。
  5. 一句台词不要横跨两个方位。人在近景里说话却标"画外念白、不露口型"＝观众读成配音事故；要念白就把这句挪到她不在焦点上的镜（比如结尾拉远镜），否则就让她正常开口。
  6. 机位高度写具体数值。"齐腰高"没有参照物（谁的腰？）——统一成固定几个高度值（本案例：0.6＝他的膝盖／1.0＝她的腰、他的肩／1.1＝他的视高／1.6＝她的视高）。

附：母题（影子、人群、倒影等）在全片出现不要超过两次；呼吸点之间要有肉眼可见的差异。

九、沉默怎么拍：在跟拍镜里沉默，不要切空镜

  • "不说话的走路"不该单独成一个没有信息的镜（切到栏杆、切到地面）——那既浪费时长，又破了"一镜到底"的连续感：沉默是一段时间，不是一次切走。正确做法：镜头继续跟着他们走，谁都不说话，把这段沉默放在跟拍镜里。
  • 落在段尾的呼吸点要换成"推动力镜"：段尾如果是"什么都没发生"，拼接后就是一段死时间。段尾应当交付一个"要发生什么"的动作（如"她转头看他、像在挑下一个问题"），让下一段的第一句直接接上。
  • 判据：问这一镜"它交付了什么信息或推动"——答不出来就说明它是空镜（或应并进相邻镜）。

案例：《一天四十三次日落》v6→v6.1，第一段尾两镜（她的眼睛 0.8 秒 + 栏杆呼吸点 1.2 秒）合并成一镜 1.6 秒"她转头看他、像在挑下一个问题"；另一处贴地滑移的沉默镜改成跟拍镜里的沉默＋她抬头看天（为下一句问话提供动机）。总长 68.4→68.0 秒。

十、对话驱动型短片：每一镜都在对话的节奏里

志光 2026-09-17 定（《一天四十三次日落》v7→v8）：

  • 特写、近景、中景、全景都可以有——它们只是对话节奏里的重音，不是"空镜"，也不是"单独为情绪存在的镜"。判断标准不是镜别，而是这一镜是否还在对话的节奏里。
  • 可以沉默，但沉默一闪而过（约 1–1.2 秒），而且紧接着就回到台词：不能有两个连续的沉默镜，也不能让沉默久留——他们一直在对话中。
  • 全片只保留开头一次建立空镜与结尾一次拉远；中间不出现"画面里没有人"的空镜，也不出现单独为情绪存在的镜头。
  • 验收动作：把所有非台词镜列出来，逐个检查"时长 ≤1.2 秒？后面紧接着是台词吗？"——有一项不满足就改。

案例：《一天四十三次日落》v7→v8，20 镜 / 54.7 秒；8 处非台词镜全部 ≤1.2 秒（开场建立 2.5 秒除外）且每一处后面立刻接台词；说话密度 72%（用户认可，不做压缩）。

十一、转场：只用三种，而且声音不断

志光 2026-09-17 定（《一天四十三次日落》v8→v9）：

  • 任何时刻至少有一方在说话：某个人沉默或思考的时候，另一个人的话还在继续——所以片子不会真的静下来。所谓"某人的沉默"是表演，不是声音上的空白。
  • 转场只有三种，且都发生在对话的节奏里：
    1. 硬切——直接切到下一镜；
    2. 路人或物体一穿而过——前景擦过画面，把镜头带过去；
    3. 对话声音延续（声音转场）——下一句台词先一步从画外进来（J-cut），或上一句的尾音留在下一镜上（L-cut）；画面切了、话没有断。
  • 禁止用"没有人物的空镜"或"纯粹的环境镜头"来转场（那正是废镜头与破节奏的来源）。
  • 落法：在非台词镜的拍摄内容里写明声音归属——如"她的问题还留在画外（她的声音、不露口型）""他的回答从画外先配音进来"，让生成端知道这一镜是有声音的。

十二、规范写在哪儿：工作文件里，不进生成文件

志光 2026-09-17 追问："转场规范要写在提示词里面吗？不应该在镜头中体现就行了吗？"——他是对的。

  • 生成文件（投喂给模型的提示词）只写影响生成的内容：全局设定保留模板原有的四个字段（核心风格／影片基调／光线设计／导演意图），其余一律不写。
  • 规则本身（转场规范、轴线与屏幕方向、机位高度基准、对话纪律）属于工作文件（分镜头脚本／检查清单），给自己和协作用，不投喂。
  • 规则的落地方式是逐镜自包含：每一镜都要写明 ① 机位在哪一侧、朝哪个方向（"侧前方（步道非江的一侧）""身后""正前方"）② 光向（顺光／逆光轮廓／侧光，并与机位几何一致）③ 声音归属（这一镜是台词镜，还是"她的问题还留在画外"）。
  • 验收动作：逐镜检查这三项是否齐备；缺一项，现场补进这一镜的镜头/拍摄内容里，而不是在全局加一条规则。
  • 光线设计字段只描述光是什么（时刻、色温、不变），不写"如何推导光向"——那是写给人看的。
