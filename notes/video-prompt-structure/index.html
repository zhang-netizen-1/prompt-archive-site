视频提示词总结构

模板视频源资料：模板-视频提示词总结构（visual-prompt-system）

视频提示词的统一拆解结构：全局设定＋参考图（可选）＋多个镜头；每个镜头由「镜头」与「拍摄内容」组成。

视频提示词的统一拆解结构：全局设定 + 参考图（可选）+ 多个镜头。参考图不是只有用户提供才使用：当视频依赖跨镜头角色、场景或道具一致性而又没有现成素材时，应先生产参考资产，再写入“参考图”；确实不需要视觉锚定时才省略。每个镜头由“镜头”和“拍摄内容”组成；其中“拍摄内容”就是该镜头具体用于生成的视频提示词。

一、总公式

视频提示词
= 全局设定
+ 参考图（可选）
+ 镜头集合

全局设定
= 核心风格
+ 影片基调
+ 光线设计
+ 导演意图

参考图
= 图片N
+ 锚定对象
+ 需要继承的特征

镜头集合
= Shot 01 + Shot 02 + … + Shot N

Shot N
= 镜头
+ 拍摄内容

这里有两个层级都使用了“镜头”一词：

  • 上层的“镜头集合”指多个 Shot；
  • 每个 Shot 内的“镜头”字段，指摄影机如何拍摄。

二、字段定义与构成

字段 定义 构成公式 回答的问题
核心风格 整部视频稳定不变的影像形态与质感 影像类型或真实程度 + 成像质感 + 影像介质或纹理 看起来像什么类型的影像？
影片基调 整部视频主要传递的情绪与审美感受 主导情绪 + 情绪关系或审美冲突 + 情绪强度 整体让人感到什么？
光线设计 光源如何塑造人物、环境和氛围 光源类型或颜色 + 光源方向 + 光线性质 + 产生的视觉效果 画面被怎样照亮？
导演意图 这场戏的叙事任务与人物变化 剧情节点 + 人物变化 + 外部画面与人物内心的关系 为什么要这样拍？
参考图（可选） 为跨镜头重复出现的角色、场景或道具提供视觉锚点；可由用户提供，也可在写视频提示词前生成 图片编号 + 锚定对象 + 需要继承的具体特征 哪张图负责决定什么？
镜头 摄影机如何取景、成像和运动 摄影机或成像质感（可选）+ 景别 + 焦段与透视（可选）+ 光圈、景深与焦点设计（按需）+ 快门、帧率等运动成像参数（按需）+ 摄影机方位、高度与拍摄角度 + 主体与构图关系 + 摄影机状态或运镜 + 起幅与落幅 摄影机从哪里、用什么画面关系、怎样拍到什么结果？
拍摄内容 当前 Shot 实际用于生成的具体提示词 该镜头内要生成的完整、具体画面描述 这一镜具体生成什么？

关键边界：

镜头 = 摄影机怎么拍
拍摄内容 = 这一镜具体生成什么

“拍摄内容”不是与具体提示词并列的附加字段，它本身就是当前 Shot 的具体提示词正文。

“镜头”字段的内部组装规则

“镜头”不等于“运镜”。运镜只是完整镜头设计中的一个变量。每个 Shot 仍只保留“镜头”和“拍摄内容”两个字段，不把景别、焦段、光圈等拆成新的同级字段。

镜头
= 摄影机或成像质感（可选）
+ 景别
+ 焦段与透视（可选）
+ 光圈、景深与焦点设计（按需）
+ 快门、帧率等运动成像参数（按需）
+ 摄影机方位、高度与拍摄角度
+ 主体与构图关系
+ 摄影机状态或运镜
+ 起幅与落幅

基本必填：

景别
+ 摄影机方位、高度与拍摄角度
+ 主体与构图关系
+ 固定状态或运镜路径
+ 起幅与落幅

按需填写：摄影机型号或成像质感、焦段、光圈、快门、帧率。只有当这些参数对应明确可见结果时才写，不能把摄影参数当作“电影感”装饰词。

不完整：35mm，T1.2，电影感。

完整：35mm广角镜头，T1.2极浅景深，焦点锁定男生双眼；
前景女生肩部与背景同学柔和虚化。

景别与焦段必须分开理解：景别决定画面取到主体的范围；焦段与拍摄距离共同决定透视关系。同为人物特写，广角近拍与中长焦远拍的空间感并不相同。

运镜必须写清物理机制及不变量，避免“固定镜头缓慢推近”这类矛盾表达：

摄影机稳定地缓慢前推，从胸部以上中近景推进至面部特写。

或

摄影机位置、朝向和高度固定，只做缓慢光学变焦拉近，
从胸部以上中近景收窄至面部特写。

固定镜头也要说明起幅与落幅。若构图全程不变，落幅写人物、物体、光影或焦点最终停留的状态。

参考资产的前置生产公式

参考图决策
= 不依赖跨镜头视觉一致性 → 省略参考图
+ 已有角色/场景/道具素材 → 直接作为参考图
+ 需要跨镜头视觉一致性但没有素材 → 先生成设定资产，再作为参考图

视频前置参考资产
= 角色设定资产
+ 场景设定资产
+ 道具设定资产
（按视频实际需要选用）

角色三视图与四视图的构成见 模板-人物设定图 › 视频辅助设定图构成公式。

角色参考资产默认优先生成四视图；只有在需要完整身体转面或进行格式对比时使用三视图。

角色、场景、道具参考资产的数量判断、生成提示词和多视图结构见 模板-角色、场景、道具提示词总结构。

参考图的“@图片N”标注规则

Shot 文本（“镜头”与“拍摄内容”）中凡引用参考图：
加“@”写作“@图片N”（N 同“参考图”模块编号）
例：@图片1锚定的模特身穿…… / 细节以@图片2为准

该标注用于生成平台把提示词与对应参考图精确绑定；除加“@”之外，不改动提示词的其他任何文字。

四、旧提示词的拆解方式

后续整理既有视频提示词时，统一按以下归属拆解，不新增同级字段：

  1. 整段视频重复生效的影像描述，归入“全局设定”；
  2. 先判断是否需要跨镜头角色、场景或道具一致性：已有素材则直接引用；需要但没有素材则先生成设定资产；确实不需要视觉锚定时才省略“参考图”；
  3. 按实际镜头切分为 Shot 01 至 Shot N；
  4. 景别、焦段与透视、光圈与景深、焦点、构图、摄影机设备、机位、角度、运动方式以及起幅与落幅，归入每个 Shot 的“镜头”；
  5. 当前 Shot 要生成的具体画面内容，完整归入“拍摄内容”。

五、与现有提示词库的关系

当前库已经有较多提示词成品与部分变量，但尚未完全按这套总结构对齐。

结构字段 当前已有内容 当前状态
核心风格 场景变量库中的美学风格包，以及各模板中的核心风格示例 有素材，尚未形成独立、统一的核心风格关键词索引
影片基调 表演变量库中的情绪表达、场景变量库中的氛围描述 有素材，但“影片基调”维度尚未独立整理
光线设计 镜头光影与质感词表-手册索引和五类双语模板中的16项光影词；镜头意图与构图光源检查表中的光源检查方法 有来源词表和检查表，尚未沉淀为本域的生产变量库
参考图（可选） 模板-人物设定图、模板-图生视频、模板-image2玩法包及资产相关模板 可使用现成素材，也可先生产角色、场景或道具设定资产再引用
镜头 运镜变量库中的运镜、视角和机位描述；既有案例中零散的景别、焦段、光圈与景深写法 运镜内容较多，但尚缺景别、焦段与透视、光圈/景深/焦点、构图等可组合变量库；完整镜头不能只由运镜组成
拍摄内容 既有模板和案例中的具体视频提示词 已有大量成品，后续按 Shot 归位即可

六、当前缺口

当前主要缺的不是更多完整提示词，而是与总结构一一对应、可查表取值的关键词索引：

  1. 摄影机镜头设计变量库：统一整理景别、机位与拍摄角度、焦段与透视、光圈/景深/焦点、构图、运镜、起幅与落幅；运镜变量库只承担其中的运镜变量；
  2. 光线设计关键词库：把现有光源、方向、光质、颜色和视觉效果整理成可组合取值；
  3. 核心风格关键词索引：整理影像类型、真实程度、成像质感与介质纹理；
  4. 影片基调关键词索引：整理主导情绪、审美关系与强度表达。

这些是后续补库方向。本笔记只确立总结构和字段定义，不在此处扩写具体关键词。

七、完整示例：深夜餐馆表白

以下为志光提供的完整示例原稿，逐字保留，不自动补写或修正文案。

核心风格：超写实青春现实主义/回忆电影感/Subtle film grain/Youthful and chaotic.
影片基调：Warm and nostalgic/Sweet and romantic/Fearless and unabashed.
光线设计：Artificial light/Warm amber overhead lighting/Dramatic rim light / Hair light.

作为色彩的视觉锚定：所有色彩按照色卡上的颜色比例分配。

作为场景的视觉锚定：深夜热闹喧嚣的中餐馆内，高中毕业班级聚餐现场。画面正中央，郑南逸身穿浅蓝色敞开衬衫站在木椅上，喝多了正情绪激昂地向下大声当众对陈安安表白。在郑南逸正下方，陈安安穿着蓝白格子衬衫坐在桌旁的椅子上，正仰起头专注地看着他，脸上带着甜蜜、惊喜且略带羞涩的笑容。他两周围簇拥着一大群年轻同学，视线都聚焦在郑南逸身上，众人正开心地笑着、起哄并热烈鼓掌。画面充满市井烟火气息，长木桌上面摆放着玻璃啤酒瓶、吃剩的餐盘、筷子和水杯。整个餐厅笼罩在顶部吊灯散发的温暖光线中，营造出一种喧嚣、狂热且极其浪漫的氛围。

作为陈安安的视觉锚定：18岁中国女学生，身高168cm,肤白貌美，蓝白格子衬衫敞开、白色内搭、黑皮带、卡其色阔腿裤，长发披肩。

作为郑南逸的视觉锚定：18岁中国男学生，身高178cm，阳光开朗，稍显调皮，短发、浅蓝衬衫敞开、白T恤、米白长裤。

Shot 01
镜头: ARRI ALEXA 35 场景双人全景，手持镜头微微晃动，35mm T1.4，主体是陈安安和郑南逸；变形宽银幕（Anamorphic）电影镜头，IMAX胶片质感，极致写实。
拍摄内容: 摄影机位于两人侧面，微仰角度。画面一开始，画左的郑南逸坐在椅子上，他推开椅子缓缓站起，身体喝多了身体轻微左右摇晃，他先踩上椅面（右脚踏上，手扶桌沿），然后左脚踏上，直起身，占据画面制高点，面对着画右坐在椅子上的陈安安，他站上椅子后深吸了一口气，目光缓慢扫过全场，周围的说话声逐渐变小，最后带着醉意的痞笑看向陈安安，暖色柔光打在郑南逸的肩膀上，画面充满青春的张狂感。画右，陈安安坐在椅子上，她面带轻微醉意，疑惑可爱的神情看着站到椅子上的郑南逸，处于画面的视觉低点。两人视线形成对角线。前景和背景都是是虚化的其他同学们在热闹起哄，有的在背景走动

八、结构化案例

案例一：咖啡店的猫

全局设定

核心风格：电影感画质，暖色调，浅景深，8K细节。
影片基调：温柔慵懒。
光线设计：咖啡馆午后，阳光从右侧照入，桌面有光斑，柔和光影。

Shot 01
镜头：咖啡杯特写，镜头开始平稳、匀速地缓慢后拉。
拍摄内容：一只戴红色领结的橘白猫坐在木质咖啡桌旁，低头轻嗅冒着热气的拿铁咖啡。咖啡馆午后，阳光从右侧照入，桌面有光斑，背景书架模糊。

Shot 02
镜头：承接 Shot 01，镜头继续平稳、匀速地缓慢后拉，最终到达猫的半身中景，全程连续无剪切。
拍摄内容：同一只戴红色领结的橘白猫抬头望向窗外的阳光，眼神温柔慵懒。主体形象和红色领结保持一致。电影感画质，暖色调，浅景深，柔和光影，8K细节。

案例二：女生偶遇暗恋对象

全局设定

核心风格：电影级写实风格，自然浅景深，细腻皮肤与发丝质感。
影片基调：短暂错愕、克制回应、强装平静、余味失落。
光线设计：午后校园林荫道，阳光从画面右上方穿过树叶，在女生的脸颊和肩膀形成柔和的斑驳侧光，背景光斑温暖明亮。

Shot 01（0–1.5秒）
镜头：35mm中景固定机位，摄影机位于林荫道侧面、与女生眼睛等高，拍摄女生从左向右行走。画面左侧预留入画空间，画面右侧是女生视线朝向的画外空间。
拍摄内容：画面内只有一位18岁女生。她从画面左侧走进，黑色长发低扎马尾，额前空气刘海，穿白色短袖衬衫校服、深蓝色百褶裙，肩背米色帆布书包。她沿林荫道向画面右侧行走，抬头看见位于画面右侧外的一对情侣中的男生，眼神突然一怔，脚步随即停住，右手下意识攥紧书包肩带。男生和他的女友均在画外。环境音：夏日蝉鸣、远处操场声、风吹树叶声。

Shot 02（1.5–3.5秒）
镜头：50mm男生过肩中近景，摄影机位于男生右后方、与女生眼睛等高。男生的后脑和右肩占据画面右侧前景约四分之一，女生位于画面左侧中景并保持清晰，男生肩部轻微虚化，女生身后的林荫道柔和虚化。
拍摄内容：画面内有两人。男生从画面右侧进入前景，面向女生停下，轻声打招呼：“哟，这么巧。”女生保持原来的外观和服装，抬眼看向男生，短暂停顿后轻声回应：“嗯，好巧。”她眼底短暂的错愕很快收住，嘴角勉强浮起一个很轻的笑，目光停留片刻后缓慢垂下，攥住书包肩带的手指稍稍收紧。男生的女友位于男生右侧画外。

Shot 03（3.5–5秒）
镜头：35mm侧面中景固定机位，摄影机回到林荫道侧面、与女生眼睛等高。女生位于画面中央偏左，画面右侧留出行走和出画空间；男生和女友保持在画面右侧外。
拍摄内容：画面内只有女生。她收回看向男生的视线，嘴角那点强撑的笑意慢慢淡去，轻轻吸气，松开攥紧的书包肩带，重新迈步向画面右侧走去。她经过摄影机前方时始终没有回头，最后从画面右侧完全出画。固定镜头停留在空下来的林荫道上，只剩夏日蝉鸣、远处操场声和风吹树叶声。

案例三：深夜拉面广告

全局设定

核心风格：《深夜食堂》日式治愈电影质感，暖黄胶片色调，颗粒感柔光。
影片基调：温柔、治愈、烟火气。
光线设计：室内暖黄吊灯为主，窗外城市雨夜冷光为辅。

Shot 01（00:00–00:03）
镜头：沸水翻滚的煮锅特写，镜头随蒸汽升腾匀速慢推，最终锁定人物俯身看锅的上半身中景，煮锅始终在画面前景。焦点从沸水顺滑转移到人物，煮锅与产品包装盒全程清晰可见。
拍摄内容：深夜日式原木风出租屋厨房，暖黄吊灯，背景是木质橱柜、小吧台和窗外的城市雨夜。一位26岁独居美食博主，齐肩短发，身穿软糯家居服，眉眼温柔，手持日式豚骨叉烧速食拉面包装盒，俯身看着锅里的沸水，指尖轻轻敲了敲包装盒，对着镜头露出温柔的笑。蒸汽在暖光下袅袅升起。对口型台词：“深夜的快乐，是一碗热拉面给的。”环境音：沸水翻滚声、窗外雨声、轻柔日系纯音乐。

Shot 02（00:03–00:06）
镜头：上帝视角俯拍，镜头从吧台全景缓缓下降，跟拍人物拆包装、放面饼和配料的动作，全程锁定操作台面和食材细节。
拍摄内容：同一位美食博主、同一间厨房，人物外观、服装、拉面产品包装保持一致。人物拆开拉面包装，将非油炸面饼放入沸水中，依次放入豚骨汤包、笋片和海苔配料，动作轻柔不疾不徐，每一样配料都清晰展示。对口型台词：“非油炸面饼，配上浓醇豚骨汤底，料超足。”暖黄灯光均匀铺满吧台，面饼、配料和蒸汽清晰可见。环境音：沸水翻滚声、包装拆开声、轻柔日系纯音乐。

Shot 03（00:06–00:09）
镜头：摄影机位置、朝向和高度固定，以光学变焦在0.5秒内从大块叉烧肉的微距特写急速拉远至人物夹起叉烧的面部近景；随后保持近景构图，焦点落在人物面部和靠近面部的叉烧，两者均清晰。
拍摄内容：同一位美食博主、同一间厨房，人物外观、服装和产品保持一致。人物用筷子夹起碗里的大块厚切叉烧，肉质纹理、肥瘦相间的细节清晰可见；她对着镜头展示叉烧，眼睛弯成月牙，满脸治愈的笑意。对口型台词：“看这大块叉烧！10分钟就能吃到门店级口感。”暖光精准打亮叉烧肉，背景轻微虚化。环境音：筷子碰撞声、窗外雨声、轻柔日系纯音乐。

Shot 04（00:09–00:12）
镜头：固定机位人物中景，摄影机位置和高度不变，镜头匀速向窗外的雨夜城市灯火横摇，再匀速横摇返回人物喝汤的中景；全程连续不切镜，返回时焦点重新锁定人物。
拍摄内容：同一位美食博主、同一间厨房，人物外观、服装、拉面碗和食材保持一致。人物挑起一筷子拉面，吹凉后送入口中，满足地眯起眼睛，再端起碗喝一口浓汤，放下碗后对着镜头露出满足的笑。对口型台词：“汤底浓而不腻，面条劲道爽滑，一口下去太暖了。”窗外雨夜冷光与室内暖黄灯光融合。环境音：吸面声、喝汤声、窗外雨声、轻柔日系纯音乐。

Shot 05（00:12–00:15）
镜头：从拉面碗的特写匀速升镜至厨房全景，最终定格在人物捧着拉面碗、对着镜头微笑的画面。
拍摄内容：同一位美食博主、同一间厨房，人物外观、服装、产品和食材保持一致。人物捧着满满一碗拉面正对镜头，碗里的叉烧、配料和浓汤清晰可见。暖黄灯光打在她的脸上，身后是雨夜的城市灯火。对口型台词：“独居的深夜，就用这碗热拉面，治愈自己吧。”拉面碗始终处于视觉核心，食材光泽和蒸汽清晰可见。环境音：窗外雨声、轻柔日系纯音乐。
