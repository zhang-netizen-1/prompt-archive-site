提炼：逐镜提示词的写法要点（供 写法规则库 扩展）

  1. 资产锚定是 {{Mixed N}} 槽位——生成时把上一环的资产图按序填入；每镜只锚定本镜出场的资产，不相关的图不挂（防止参考污染）；
  2. 三段式时段结构——每时段七字段：画面（主体+动作+光线+景别）/ 禁止×5 / 约束×5-6 / 站位与朝向 / 运镜 / 音效 / 简述；禁止与约束分工：禁止=防跑偏红线，约束=保质量底线；
  3. 前镜衔接描述——每镜开头复述上镜末态（约 80 字），这是跨镜一致性的文本机制：模型靠它延续服装/道具/情绪状态；
  4. 运镜写"类型+速度+目的"（"极缓慢的低角度仰拍推镜头，彰显绝对高压"），与本域运镜库口径一致；
  5. 台词三保险——时段画面里写台词全文 + 禁止"台词未讲出/漏念" + 输出约束"口型严丝合缝"；
  6. 输出约束 = 全镜统一性清单——服装/道具逻辑/口型/光影基调/禁杂项/氛围六条，跨时段生效；
  7. 光影跟随情绪曲线（与拆解分镜规则的光影叙事路由一致）：镜1-2冷蓝→镜3-7威压逆光→镜8暗转明→镜9-11暖金爆发→镜14史诗收尾；
