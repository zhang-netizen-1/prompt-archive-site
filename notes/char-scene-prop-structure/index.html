角色、场景、道具提示词总结构

模板图像源资料：模板-角色、场景、道具提示词总结构（visual-prompt-system）

三类视觉资产的统一提示词结构：角色四视图、场景设定与道具设计图。

用于视频生成之前的参考资产生产。一个独立视觉锚定对象对应一份生成提示词和一张多视图参考图；没有参考需求时不创建对应资产。

一、总构成

视频前置参考资产
= 角色四视图
+ 场景四视角
+ 道具六视图
（按项目实际需要选用）
单份参考资产生成提示词
= 资产对象定义
+ 多视图版式
+ 各分栏视角
+ 跨视图一致性约束
+ 干净资产约束
+ 统一视觉风格
统一视觉风格
= 题材
+ 画风
+ 渲染或成像方式

数量公式

参考资产提示词数量
= 需要独立保持一致的视觉锚定对象数量
  • 一个角色即使出现在多个 Shot 中，仍对应一份角色四视图提示词和一张角色四视图。
  • 一张多视图参考图内部虽然包含多个分栏，仍只算一个对象的一张参考图。
  • 已经完整包含在角色设定图中的随身物品，不自动拆成独立道具；只有需要独立锚定或特写时才单独生成。
  • 同一场景重复出现在多个 Shot 中，只生成一张场景四视角；空间发生实质变化时再拆成新的场景资产。

二、角色四视图

构成公式

角色四视图
= 角色描述
+ 9:16竖幅
+ 2×2四宫格
+ 左上：正面头部胸像
+ 右上：45°侧脸胸像
+ 左下：全身背面视图
+ 右下：全身微侧颈部以下全身图（不包含头部）
+ 人物一致性约束
+ 统一背景与光影

角色描述公式

角色描述
= 身份与年龄
+ 性别与地域特征
+ 肤色与气质
+ 自然生物特征与轻微肤色差异（必填）
+ 发型与发色
+ 面部辨识点
+ 身形
+ 服装
+ 随身配饰

真人感必填项

真人感必填项
= 可见但克制的生物特征
+ 符合角色年龄与身份的自然皮肤细节
+ 避免过度磨皮与塑料陶瓷肤质

人物参考图不能只写“精致、白皙、细腻”等趋向完美的形容词。角色描述必须保留自然生物特征；具体表现可从自然毛孔、面部细软绒毛、若隐若现的毛细血管、轻微肤色差异、雀斑、淡痘印或细纹中按角色选取，不要求机械堆满。

标准模板

帮我生成一张{角色名称}角色设定图：

{角色描述}

{真人感必填项：自然生物特征、符合年龄与身份的皮肤细节、反过度磨皮约束}

人物四视图格式：
双手自然垂落身体两侧，2×2四宫格角色参考图，格式9:16，四个独立等分画面，左上正面头部胸像，右上45°侧脸胸像，左下全身背面视图，右下全身微侧颈部以下全身图（不包含头部），统一纯色浅灰背景，统一光影，四个视角人物样貌、服装、发型完全一致，标准建模角色设定稿，清晰区分四个视角，干净无干扰背景。

{统一视觉风格}

主要锚定内容

角色四视图负责锚定
= 五官与脸型
+ 正面与45°侧脸
+ 肤色与发型
+ 身高与身体比例
+ 背面造型
+ 服装与配饰的整体样式

《盛唐》旧案例中的角色四视图是“头部特写占1/3＋三个全身转面占2/3”的横向结构，不作为当前默认角色格式。当前统一采用上述9:16、2×2四宫格。

三视图保留为格式对比，或需要完整正面、90°侧面、背面身体转面时的备选；具体结构见 模板-人物设定图 › 视频参考用三视图。

当前验收重点

  • 四格必须是同一个角色，五官、脸型、肤色、发型、身形、服装和配饰保持一致。
  • 左上与右上的正面、45°侧脸必须能够识别为同一张脸。
  • 左下必须完整展示包含头部在内的全身背面；右下必须是颈部以下的微侧全身，不包含头部。
  • 四格各自独立、边界清晰，不得出现无关人物、场景或剧情动作。
  • 必须呈现与角色年龄、身份一致的自然生物特征和皮肤细节，不得生成过度磨皮或塑料陶瓷肤质。

三、场景四视角

当前结构来自 范例-盛唐资产包-角色场景道具设定图，待更多真实案例继续验证。

构成公式

场景四视角
= 场景描述
+ 整幅横向16:9画面
+ 2×2四宫格
+ 每格为独立16:9横向画面
+ 左上：正面中心线大全景
+ 右上：左前方45°大全景
+ 左下：右前方45°大全景
+ 右下：场景最深处向外拍摄的正中心全景
+ 空场景约束
+ 空间一致性约束
+ 统一视觉风格

场景描述公式

场景描述
= 名称与空间定位
+ 室内或室外
+ 空间尺度
+ 前景元素
+ 背景元素
+ 氛围

标准模板

帮我生成一张{场景名称}场景设定图：

场景描述：
名称：{场景名称与定位}。
描述：{室内或室外、空间尺度、宏观或微观}。
前背景：{背景元素}背景，{前景元素}前景。
氛围：{场景氛围}。

场景四视角格式：
整幅采用横向16:9画面，以2行2列的干净网格分成四个独立等分画面，每格均为独立的16:9横向画面。左上为正面中心线大全景，摄影机正对场景中心轴，构图严格居中，同时展示顶面、底面和完整空间层次；右上为以正面中心线为基准、摄影机移动至场景左前方45°的大全景；左下为摄影机移动至场景右前方45°的大全景；右下为摄影机位于场景最深处、向外拍摄的正中心全景。

四个视角必须表现同一地点、同一时间、同一天气、同一光源、同一空间结构、同一空间比例和同一美术风格。所有建筑、陈设、主体位置、材质和色彩保持一致，空间连贯，画面端正，无透视畸变。

这是空场景参考图，四个画面必须空无一人。不得出现人物、人群、背影、剪影、人脸、手脚、人物倒影、人物影子、照片人物、屏幕人物、镜中人物、剧情事件或人物活动。不得出现文字、水印、标签或UI元素。

{统一视觉风格}

主要锚定内容

场景四视角负责锚定
= 空间结构
+ 中心轴与出入口
+ 建筑和陈设关系
+ 前中后景层次
+ 材质与色彩
+ 时间、天气与光源
+ 整体美术风格

当前验收重点

  • 四格必须是同一个场景，不能生成四个相似但不同的地点。
  • 正面、左右45°和反向视角不能重复。
  • 核心建筑、柱位、出入口和大型陈设应跨格对应。
  • 场景图用于视频视觉锚定，不等同于可精确建模的建筑工程图。

四、道具六视图

当前结构来自 范例-盛唐资产包-角色场景道具设定图，待更多真实案例继续验证。

构成公式

道具六视图
= 道具描述
+ 横向构图
+ 2×3六宫格
+ 左上：正面视图
+ 上中：背面视图
+ 右上：左侧视图
+ 左下：右侧视图
+ 下中：顶部俯视图
+ 右下：底部仰视图
+ 近似正交投影
+ 道具一致性约束
+ 干净背景约束
+ 统一视觉风格

道具描述公式

道具描述
= 名称与用途
+ 整体尺寸
+ 部件尺寸
+ 结构与造型
+ 材质与颜色
+ 使用痕迹

标准模板

帮我生成一张{道具名称}道具设定图：

道具描述：
名称：{道具名称与用途}。
尺寸：{整体尺寸与关键部件尺寸}。
结构：{整体造型、组成部件和连接关系}。
材质：{各部件材质、颜色和表面质感}。
特征：{磨损、灰尘、氧化、划痕或其他使用痕迹}。

道具六视图格式：
高质量专业道具多角度展示图，横向构图，以2行3列的干净网格分成六个独立等分画面。左上为绝对正面视图，上中为绝对背面视图，右上为绝对左侧视图，左下为绝对右侧视图，下中为绝对顶部俯视图，右下为绝对底部仰视图。

六个画面必须展示同一件道具，材质、颜色、比例、尺寸、结构和使用痕迹完全一致。所有视角不得重复；顶部和底部必须垂直正交拍摄，不得用斜后方视角代替底部仰视。采用超长焦镜头或移轴镜头效果，将透视变形降到最低，接近正交投影；物体在每格中居中，缩放比例、中心线和朝向规范保持一致，完整轮廓入画，无裁剪、倾斜、旋转或透视畸变。

统一纯白色背景和专业产品影棚光线。不得出现人物、手脚、场景、建筑、自然景观、其他道具、剧情事件、文字、水印、logo或UI元素。

{统一视觉风格}

主要锚定内容

道具六视图负责锚定
= 整体轮廓
+ 正反面结构
+ 左右侧结构
+ 顶部与底部结构
+ 尺寸比例
+ 材质与颜色
+ 使用痕迹

当前验收重点

  • 六个格子的视角必须一一对应，不能重复生成侧面或背面。
  • 顶部俯视和底部仰视必须真实呈现对应表面。
  • 关键部件的数量、位置和连接关系应跨格一致。
  • 六视图用于视频道具一致性锚定；近景英雄道具仍可能需要额外局部特写。

五、资产清单与交付顺序

故事梗概或分镜表
→ 识别跨镜头重复出现的角色、场景和道具
→ 合并同一对象，形成独立视觉锚定对象清单
→ 为每个对象编写对应的多视图生成提示词
→ 生成参考图
→ 按各类型验收重点确认
→ 在视频提示词中声明每张图的锚定职责
→ 编写带连续时间段的各个 Shot

项目级交付公式

完整视频生成包
= N份参考资产生成提示词
+ N张确认后的参考图
+ 1份引用这些参考图的完整视频提示词

没有参考资产时，交付物中不出现参考资产提示词、参考图或参考图职责模块。

六、与视频提示词的关系

本模板负责生成视频之前的资产生产；模板-视频提示词总结构负责将已确认的参考图写入视频生成提示词。

参考资产提示词
→ 生成并确认多视图参考图
→ 视频提示词中的参考图职责声明
→ Shot 01 至 Shot N

参考资产只定义稳定视觉信息，不提前演出剧情：

  • 角色保持中性表情、自然站姿和干净照明；
  • 场景保持空场景，不注入人物和剧情事件；
  • 道具保持独立陈列，不出现手持动作和剧情环境。
