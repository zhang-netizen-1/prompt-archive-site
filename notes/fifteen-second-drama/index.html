使用流程

  1. 明确任务→在变量清单确认需要的变量类；
  2. 到对应变量库按选档规则取值（整条搬用）；
  3. 填入下方模板结构；
  4. 对照组合规则检查冲突；
  5. 生成后按示例库同型案例核对。

模板结构（三选一节奏骨架）

A 战斗型：0–3对峙 → 3–6交锋 → 6–8蓄力终结 → 8–10反应 → 10–15结果与余韵 B 剧情型：0–3.5登场 → 3.5–7冲突触发 → 7–8揭示 → 8–12情绪展开 → 12–15收束 C 喜剧型：0–4误导建立 → 4–6误导加深 → 6–7揭晓 → 7–10反转展开 → 10–15笑点收束

每镜：{景别/机位}，{主体动作}，{对白≤15字}，{声音事件}。

组装规则

  1. 先选节奏型，再逐镜填；叙事节拍≠镜头数，一个节拍可含多镜；
  2. 每镜只交代一个主要信息；对白先试读——三秒放不下长句（约≤15字）；
  3. 揭示/反转拍要短，后果/展开拍要长；
  4. 结尾停在「正在变化而未解决的事件」上，不任意黑屏；
  5. 全片总长逐镜相加必须=15秒，含定格与静默。
