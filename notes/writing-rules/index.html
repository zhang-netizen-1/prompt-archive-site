规则图像＋视频共用源资料：写法规则库（visual-prompt-system）

解决「变量库都是跑过的固定描述，无法举一反三」的问题。

核心机制（志光 2026-09-04 定型）：有限的正本 + 无限的生成 + 有门槛的回流。 固定描述是训练数据（质量锚点），写法规则是模型（组合公式保证结构下限），志光的确认是质量门禁。 生成端无限，库存端有限且验证过——每回流一个好条目，库+1、规则再验证，飞轮复利。 缺任何一个环节都只是排列组合，不叫举一反三。三类生成规则：组合公式（a+b+c 怎么拼）、条件路由（如果 x 则用 y）、参数化（把死条目变成活模板）。条目按"引用方式"分：公式可直接套，条件表按情况查，参数化条目替换槽位后使用。

与变量库的分工

  • 变量库 = 成品取值（整条搬用，禁改写——零号条款）
  • 本库 = 生成规则（教你造新条目，是活的方法）
  • 一个新提示词 = 写法规则（骨架）+ 变量库取值（填料）+ 高频包（就近弹药）

一、组合公式（A+B+C 结构）

即梦影视级公式（seedance 全系通用骨架）

[运镜方式] + [拍摄内容] + [运镜描述] + [表达的意境/效果]

示例拆解：

槽位 填入
运镜方式 跟镜头
拍摄内容 一只在城市的水泥路上奔跑的小猫
运镜描述 匀速跟拍，与主体步行速度（约每秒 1.2 米）完全同步，前后左右偏差不超过 30 厘米
表达意境 表达出小猫咪对城市的好奇

施法镜头公式（特效库·结构化写法）

时间 + 动态运镜 + 手势变换(具体手指怎么放) + 粒子特效

示例：1.2-2.0s, 手部特写 + 高频震动，剑指快速拆解重组为三角尖塔印(拇指相抵，其余四指并拢相触，形成三角形)，指尖相触处迸出第一缕刺眼金光

规则：手势从手指大全选 2–4 个为一组；每个手势只在第一次出现时解释手指摆法。

武器特效总公式（动作库）

视频基础参数 + 风格场景设定 + 分镜、招数光效

国风武侠·时序结构（0.5秒节拍制）

风格设定(一句) + 基础参数(一句) + 镜头提示词：
0.0s-0.5s，[运镜→锁焦方式]，[画面描述+特效]
0.5s-1.0s，[运镜→锁焦方式]，[画面描述+特效]
……

每 0.5 秒一个节拍，每拍=运镜+画面+特效三件套；「碰撞点极速推镜锁焦」「贴身平行极速横移运镜→躯干纵向锁焦」这类短句是拍的公式化运镜写法，可替换复用。

微表情逐拍结构

0至{t1}秒：{情绪链第1拍}。
{t1}至{t2}秒：{情绪链第2拍}。……

各拍时长相加=总时长；逐拍之间要有因果承接（震惊→冷笑→强笑→崩溃）。

二、条件路由（如果 X 则 Y）

运镜选档路由

条件 查表
有明确情绪诉求 先查「情绪化运镜」表（聚焦式推进=沉浸、抽离式后拉=疏离）
一般主体运动 「镜头运动方向」选主运镜
需要空间语境 叠加「视角层级」（远全中近特写+俯仰微距）
复合运动需求 直接查「复合运镜」组合条目（360°环绕+急推=震惊反转）
Seedance 2.5 任务 优先用 2.5 图解版条目

Seedance 2.0 特性增强路由（写运镜时叠加的修饰规则）

  • 智能运动追踪场景 → 加「自适应速度」「轻微晃动」「动态模糊」增强真实感
  • 强调镜头物理感 → 加「镜头呼吸感」「透视变化」
  • 真实摄影质感 → 加「光斑虚化」「大气透视」
  • 情绪传递场景 → 加景深控制与细节强化

打斗距离路由

交战距离 动作档
近身 拳/短兵器档
兵器接触距离 刀剑棍缠斗档
中距离 鞭/锁链/流星锤档
远程 弓箭/暗器/飞镖档

打斗节奏路由

每次交锋必须有可见结果；3 秒内最多 2 次接触；连续动作用衔接快切句式；终结拍建议慢镜。

人设图类型路由

需求 图类型
基础外观定稿 基础三视图
带表情设定 标准角色设定图（+正面微笑特写）
影视级全套 完整角色设定图（五视图+头部组+材质组，16:9，需 seedream 5.0-lite）
道具 道具设定图（工业设计三视图）

三、参数化条目（活模板）

仙侠粒子「对应元素」模式

粒子特效描述中的元素是可替换参数，同一句式换元素即得全系：

漫天{元素}粒子悬停，掌心{元素}法阵如龟裂大地蔓延，金光爆闪，{元素}粒子炸裂成亿万金刚砂刃激射
  • {元素} ∈ 金/木/水/火/土/冰/雷…
  • 配色规则：金色=金光、水系=寒光、火系=赤焰——元素与光效词联动替换

灵力粒子偷懒法

直接用「X 色灵力粒子」：金色灵力粒子 / 绿色灵力粒子 / 粉色粒子——单色即成立，不用展开法阵描述。

五镜系列槽位结构（每套 10 组同构）

镜N {t1}-{t2}：{景别/机位}，{主体动作}，{对白≤15字}，{声音事件}

五镜每组都是这个骨架的 5 次实例化——换题材=换 {主体动作} 和 {场景}，骨架不动。

使用顺序

  1. 输入是一段故事描述（非单镜任务）→ 先走 拆解分镜规则 切幕拆镜，产出分镜表后逐镜回到本库； 0b. 成片需要分段生成（单次生成装不下）→ 先读 多段成片的分段纪律与连续性；台词要定语气 → 见 台词标点与配音语气；
  2. 接任务 → 先在本库找对应的组合公式定骨架；
  3. 骨架槽位 → 到变量库/高频包取值填料；
  4. 选档拿不准 → 查条件路由表；
  5. 同族变体（换元素/换题材）→ 用参数化条目替换生成；
  6. 生成的新条目效果好 → 按§零条款，经志光确认后收入变量库（你亲述=合法新增）。

维护规则

  • 本库是方法层，不受零号条款"原文一字不动"约束（那是变量库取值层的宪法）——本库的公式/路由可以随经验迭代；
  • 但引用的示例（如即梦公式的小猫例）保持原样，不改动来源内容；
  • 新公式来源：志光口述 > 从高表现条目反推（标注"反推自XX案例"）。
