拆解分镜规则

把叙事意图拆成镜头序列的方法：景别、机位与叙事功能的对应。

全流程缺失一环的补全：一段文字描述 → 分镜头表。位于写法规则库的下游、模板组装的上游——故事进来，分镜表出去，再走变量取值组装提示词。

一段故事描述 → [本规则:拆解分镜] → 分镜表 → 写法规则库选公式 → 变量取值 → 提示词 → 生成 → 回流

一、分镜表标准字段（9 列）

来自《我在盛唐写天下》全流程范例（14 镜完整拆解，见附范例）：

字段 管什么 填写要点
镜号 顺序 线性编号
时长 该镜秒数 与叙事功能匹配（见时长分配规则）
画面描述 谁在哪做什么 主语+动作+环境，一段一句
景别 取景范围 大特写/特写/近景/中近景/半身/中景/中远景/全景/大远景
光影氛围 光源+色调+情绪 三要素：光从哪来/什么色调/传递什么感受
对白·旁白 说话人+台词 无台词镜用＋占位；台词≤15字/3秒
音效 事件音+环境底 按层填：主事件音+环境底+细节音
运镜 相机行为 运动类型+速度+起止（忌只写词不写路径）
最终提示词 生成用 由前列组装，本表产出后填

二、拆解公式：幕→节拍→镜

故事描述
→ 切幕（场景/时空变化=幕边界）
→ 每幕找节拍（信息或情绪变化一次=1节拍）
→ 每节拍定镜数与时长（节拍可含多镜）
→ 逐镜填9列

幕切分信号：场景标注（【盛唐·金銮殿·日】）、时空跳转（穿越/黑屏转场）、叙事单元完成。

节拍密度：爽文节奏下 60–90 秒 ≈ 12–14 镜；每幕 3–5 镜。范例分布：序幕2镜（现代压抑）→ 第一幕5镜（威压升级：睁眼/斥责/质疑/通牒/刀光）→ 第二幕3镜（转折爆发：起身/望外/吟诗）→ 第三幕4镜（余韵收束：震撼/赞许/许愿/拉远）。

三、条件路由

时空穿越类拆解路由（范例即模板）

拍 功能 范例镜头
旧时空崩溃 用感官失控（屏幕蓝光→晃动→黑屏） 镜1–2
新时空着陆 睁眼+环境全景+身份错位三连 镜3
威压建立 反派施压逐级加码（斥责→通牒→刀光） 镜4–7
转折爆发 主角状态转变（恐慌→冷静→起身→宣言） 镜8–10
世界反馈 配角反应+权威认可 镜11–12
收束拉远 个人宏愿+大远景史诗收尾 镜13–14

情绪升级路由

威压段每镜情绪强度递增（压抑→震惊→恐慌→死寂）；爆发段反向释放（冷静→燃→辉煌→史诗）。相邻镜必须有变化，同强度连排两镜即合并。

时长分配规则

镜类型 参考时长 范例
建立镜（环境/身份） 8–12s 镜1、3
反应镜（情绪特写） 6–8s 镜2、5
对峙镜（施压/宣言） 8–15s 镜6、10
群像反馈镜 10–12s 镜11
史诗收尾镜 10–12s 镜14

对白镜按台词实测时长+1s余量；无对白纯表演镜 6–8s。

生成切分规则（志光 2026-09-04 口述定型）

前提：先有整个 SOP，再谈单镜生成。 分镜表是生产计划，不是一次成片的脚本——正片通常一个镜头一个镜头生成，后期合成。

切分策略 单镜时长 适用
标准切分（推荐默认） ≈5s/镜 大部分镜头——后期合成好操作：单镜短=重生成成本低、剪辑自由度高、坏一镜只补一镜
中长切分 15s/镜 强连续性段落（对峙、追逐），模型单次叙事能力可覆盖时
长镜头 30s/镜 有人就喜欢长镜头——一镜到底的沉浸段落，接受重抽成本换连续性

判定依据是后期操作成本，不是模型上限：生成时长通常 5/15/30 秒档位，但档位大≠该用大——切得细，合成时才有重组自由。

范例对照：《盛唐》14 镜平均 9.3s/镜——按标准切分应拆为约 26 个 5s 镜（对峙镜 6、10 的 12–15s 拆 2–3 镜；建立/群像镜 8–12s 拆 2 镜）。原表是叙事分镜（按节拍切），进生产前需做生成切分（按 5s 档重切）——两层切分是两个动作。

SOP 全景（知道整片怎么拼，才知道每镜怎么生成）：

故事描述 → 拆解分镜(叙事分镜:按幕/节拍切)
        → 生成切分(按5/15/30s档重切,默认5s)
        → 资产生产(分镜表高亮关键词=资产需求;角色四视图/场景四视角空底图/道具六视图)
        → 逐镜生成(资产参考图+提示词=写法规则+变量取值)
        → 后期合成(剪辑重组/调色/配乐/对白)

资产层规则（范例提炼）：分镜表里的蓝色高亮关键词（人名/地名/道具）就是资产需求清单——每镜提到谁就产谁的设定图。三类模板：角色四视图（特写1/3+三视图2/3）/场景四视角 2×2（空场景底图，禁任何人影——人物逐镜注入，资产与表演分离）/道具六视图 2×3（尺寸+逐视图说明+使用痕迹）。全片统一[视觉风格]尾缀。详见 范例-盛唐资产包-角色场景道具设定图。

逐镜生成规则（范例提炼）：每镜提示词 = 资产图锚定（{{Mixed N}} 槽位，只挂本镜出场资产）→ 出场角色（含身高）→ 背景场景（光影基调+空间尺度）→ 参考图使用规则（角色/场景/道具三类"只参考…不参考…"，防多视图污染）→ 衔接（首镜="故事开篇"，其余复述上镜末态 ~80 字，这是跨镜一致性的文本机制）→ 时段提示词（画面/禁止/约束/站位朝向/运镜/音效/简述七字段）→ 输出约束（服装/道具逻辑/口型/光影/禁杂项/氛围六条全镜清单）。台词三保险：画面写全文+禁止"漏念"+约束"口型对齐"。14 镜逐字存档见 范例-盛唐分镜提示词-1至14镜全量。

光影叙事路由

叙事阶段 光影策略 范例
压抑段 冷蓝灰低饱和+单一冷光源 镜1–2
威压段 逆光剪影+硬光反差 镜3–7
转折点 明暗交接（暗转明） 镜8
爆发段 暖金高饱和占满 镜9–11
收尾 极致史诗暖金+朱红 镜13–14

光影跟着情绪曲线走，不是每镜独立选。

四、与现有系统的接口

  1. 分镜表「运镜」列取值 → 运镜变量库 按选档路由；
  2. 「光影氛围」→ 场景变量库 风格包；
  3. 「音效」→ 方法层《短片声音分层与声画关系》三 layer；
  4. 每镜「最终提示词」组装 → 对应模板（十五秒短剧/单镜头运动）；
  5. 角色跨镜一致（沈昭昭现代/唐代两版）→ 系列视频角色与声音一致性。
