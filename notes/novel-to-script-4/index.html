小说等转脚本（4 类元提示词）

方法视频源资料：✏️脚本-小说等转脚本-4类（prompts）

4 类「小说/故事转脚本」LLM 元提示词：按剧情转脚本，含人设与原著一致性限制条件、脚本字段要求（镜头号/运镜/景别/台词/音效/时长）与分镜图描述规范。

<!--根据剧情/故事转脚本-->
# 任务
阅读并理解我所提供的故事内容，并把它转化成短剧/漫剧脚本
# 限制条件
1. 所有角色的人设、行为逻辑、人物关系、台词风格、命运结局，必须100%严格遵循用户提供的完整原著故事内容，不得擅自新增、修改、删减人物核心设定与原著明确描写的关键行为；
2. 若本模块的角色细节设定，与用户提供的原著故事原文有冲突，无条件以原著故事原文为准，不得自行发挥；
3. 脚本中角色的台词、动作、神态、心理活动描写，必须服务于原著故事的剧情推进与人物弧光，不得添加与原著无关的人设标签、支线剧情与戏份；
4. 严格区分核心主角、次要配角、工具人角色的叙事权重，配角/工具人不得抢戏、不得擅自加戏，戏份占比严格贴合原著。
# 内容要求
1. 脚本需包含镜头号、运镜、景别、画面描述、画面补充细节、人物台词、音效设计、镜头时长
2. 其中画面描述的部分我将用于图片生成分镜图，请满足如下要求
    - 描述需要精简，请勿超过200个字
    - 每个描述都是一个完整的画面，包含视觉风格（例如：二次元动漫、3D动画等）、人物、场景等内容
3. 运镜和景别需根据故事脉络丰富多彩，包括但不限于远景、全景、特写等，千万不要大篇幅使用单一镜头
4. 结合我给你的单集时长去自动规划镜头数量、剧情的反转、高潮、推进以及每个镜头时长
- 4.1 若时长<=60s，则满足如下条件
    - 开篇：0.5-1.5秒，2-3个镜头，占时≤3秒
    - 剧情主体：2-3秒/个，15-22个镜头，占时45-50 秒
    - 小高潮反转：1-2秒/个，2-3个镜头，占时3-5秒
    - 结尾留坑：3-4秒，1个镜头，占时3-4秒
    - 总镜头数：20-30个
<!--阿拉赛博蕾-->
- 4.2 若时长>60s，且<=120s，则满足如下条件
   - 开篇：0.5-1.5秒，3-4个镜头，占时≤3 秒
    - 剧情推进A段：2-3秒/个，12-15个镜头，占时30-35 秒
    - 第一个小高潮：1-2秒/个，3-4个镜头，占时4-6 秒
    - 剧情推进 B 段：2-4秒/个，12-15个镜头，占时35-40秒
    - 结尾大反转+留坑：2-4秒/个，3-5个镜头，占时10-15秒
    - 总镜头数：35-45个
- 4.3 若时长>120s且<=180s，则满足如下条件
    - 开篇钩子：0.5-2秒，3-5个镜头，占时≤5 秒
    - 剧情第一幕：2-3秒/个，15-18个镜头，占时 40-45秒
    - 第一个反转高潮：1-2秒/个，4-5个镜头，占时 5-8秒
    - 剧情第二幕：3-4秒/个，15-18个镜头，占时 45-50秒
    - 第二个反转高潮：1-2秒/个，3-4个镜头，占时 4-6秒
    - 结尾悬念留坑：3-5秒/个，2-3个镜头，占时 8-12秒
    - 总镜头数：45-60个
# 工作流程
1. 步骤1: 要求用户提供该剧的风格、总集数及每集时长。提问方式如下
    - 请告诉我本剧的风格、总集数及所预期的每集时长
2. 步骤2: 结合用户给的故事附件及输出内容综合规划输出脚本csv文件
3. 步骤3: 该csv文件可支持下载

第一章/第1集

这个提示词需要跟Ai来来回回沟通很久，如果想法比较模糊，建议先跟Ai把故事聊清楚了之后，用其他三段提示词

<!--模糊想法转脚本-->
# 角色
你是一名从业10年的影视编剧，擅长把碎片化的灵感打磨成逻辑完整、有共情力的故事。
# 任务
将我的想法转化成短剧/漫剧脚本
# 工作流程
1. 步骤1: 结合我的要求为我生成3个版本的故事梗概（对应a\b\c），每个版本不要超过300字，并询问我喜欢哪一个；
2. 步骤2: 在我做出选择后，结合具体的故事梗概为我输出人物小传。人物小传要求如下：
    - 包含人物的基本信息、外貌特征、性格底色、成长背景、核心欲望、内心恐惧、人物弧光（从开头到结局的成长变化）
    - 补充3个能体现人物性格的标志性细节动作/口头禅/习惯，比如“紧张的时候会攥紧外卖袋的提手，说话不敢看人的眼睛”
    - 人物行为逻辑自洽，符合故事的背景和核心情绪，不悬浮
3. 步骤3: 当故事梗概及人物小传确定后，为我生成故事大纲及分集大纲
4. 步骤4: 当步骤1～3均完成后，为我生成标准格式单场剧本脚本，脚本内容包含：
    - 镜头号、运镜、景别、画面描述、画面补充细节、人物台词、音效设计、镜头时长
# 要求
请严格按照我所规划的工作流程执行命令，不要跳步

网梗段子转脚本：

注意这个提示词是根据15s的剧情写的，所以内容很短

# 任务
阅读并理解用户提供的网梗、热梗、段子、神评论、搞笑名场面等核心内容，100%还原梗的核心笑点、反转内核与名场面精髓，转化为严格控制在15s以内的竖屏短视频/漫剧/真人出镜脚本
# 限制条件
1. 脚本中所有的台词、动作、神态、画面设计，必须全程服务于原梗的笑点落地与反转呈现，每一秒内容都必须为梗的核心服务，严禁出现任何无意义的铺垫、冗余镜头与无效内容；
2. 总时长<15s，核心爆点/反转笑点必须在视频开播后8s内完成呈现，严格适配短视频平台黄金停留规则；
3. 针对谐音梗、方言梗、特定圈层梗，必须通过字幕、画面补充等方式保障笑点可被快速理解，不得丢失梗的核心趣味点，同时严禁篡改原梗原意。
# 内容要求
1. 脚本必填字段：镜头号、景别、运镜、竖屏画面描述、人物台词/醒目字幕、音效/BGM设计、单镜头时长、总时长校验，所有字段必须完整填写，无遗漏；
2. 竖屏画面描述要求（用于AI生成分镜图）：
    - 描述必须精简，单条画面描述严禁超过100个字；
    - 每条描述对应一个完整的竖屏9:16画面，必须明确标注视觉风格（如：真人搞笑出镜、沙雕2D动画、二次元动漫、写实3D等）、核心人物、场景、关键动作，适配竖屏居中构图，符合AI生图逻辑；
3. 运镜与景别要求：
    - 必须根据梗的节奏灵活切换景别与运镜，涵盖特写（抓表情/细节）、近景、中景、全景等，严禁大篇幅使用单一景别/运镜；
    - 单镜头时长严禁超过3s，全程快切节奏，适配短视频用户观看习惯，无拖沓长镜头；
4. 15s内专属时长&镜头数硬性规则（总时长严格锁定8-15s，严禁超时）：
    - 开篇：0.5-1s，2-3个镜头，占时≤3s
    - 剧情主体：1-2s/个，3-4个镜头，占时3-6s
    - 小高潮反转：0.5-1.5s/个，2-3个镜头，占时1-4s
    - 结尾留钩：1-2s，1个镜头，占时1-2s
    - 总镜头数：8-11个
5. 额外适配要求：
    - 台词必须口语化、接地气，完全贴合网梗的传播语境，严禁书面化、冗长化表达，核心台词必须搭配醒目全屏字幕，适配静音观看场景；
    - 音效/BGM必须匹配梗的风格，优先选用短视频平台热门BGM、梗专属音效、搞笑卡点音效，精准踩中笑点与镜头切换节点。
# 工作流程
1. 步骤1: 要求用户提供核心信息，提问方式固定如下
    - 请告诉我该网梗/段子的完整核心内容、视频呈现风格、预期精准时长（需在8-15s区间内）
2. 步骤2: 结合用户提供的原梗内容，严格遵循上述所有规则，完成单条竖屏脚本的全字段创作，确保时长合规、笑点完整、适配短视频传播；
3. 步骤3: 可同步输出符合规范的csv格式脚本文件，支持下载使用。

## 任务
深度阅读、共情并**100%严格遵循用户提供的真实感人/励志故事完整素材**，精准提炼故事核心情感内核（温暖感人/正向励志），绝对尊重真实人物原型、真实事件脉络、真实人生经历，将其转化为适配竖屏短视频传播、情绪饱满、节奏精准的短剧/漫剧标准化分镜脚本。

## 限制条件
1. 所有真实人物的原型人设、人生经历、行为逻辑、人物关系、台词风格、事件结局，必须100%严格遵循用户提供的真实故事原文/真实事件素材，不得擅自新增、修改、删减人物核心设定与原文明确记载的关键真实事件、关键人生节点；**严禁为了戏剧效果虚构、歪曲真实人物的经历与品格**。
2. 若本模块的细节设定，与用户提供的真实故事原文/真实事件素材有冲突，无条件以用户提供的真实素材为准，不得自行发挥、虚构情节；严禁篡改真实故事的核心事实与情感内核。
3. 脚本中人物的台词、动作、神态、心理活动描写，必须严格贴合真实人物的真实状态，服务于真实故事的情感传递（感人/励志核心）与人物真实成长弧光，不得添加与真实故事无关的人设标签、支线剧情、狗血戏份与过度戏剧化改编。
4. 严格区分核心故事主人公、次要亲历者、背景人物的叙事权重，次要人物/背景人物不得抢戏、不得擅自加戏，戏份占比严格贴合真实故事的叙事重心，始终聚焦主人公的感人/励志核心主线。
5. 必须坚守真实故事的正向价值观，聚焦感人至深的真情内核、励志向上的成长力量，不得添加低俗、博眼球、歪曲正能量的内容；**严禁消费苦难、过度渲染负面情绪**，始终以传递温暖、治愈、向上的力量为核心导向。

## 内容要求
1. 脚本需完整包含镜头号、运镜、景别、画面描述、画面补充细节、人物台词、音效设计、镜头时长，所有镜头设计优先服务于真实故事的情感递进与核心情绪表达。
2. 其中画面描述部分将用于AI生成分镜图，需严格满足如下要求：
    - 描述精简，单条画面描述请勿超过200个字
    - 每条描述对应一个完整的独立画面，必须明确标注视觉风格（例如：纪实真人实拍风、写实3D动画、治愈二次元动漫、国风插画等）、核心人物、场景、核心动作等关键视觉信息
    - 视觉风格需贴合真实故事的年代、地域、场景属性，兼顾纪实感与画面感染力，人物形象需贴合真实原型的特征描述，严禁过度美化/丑化
3. 运镜和景别需根据故事的情绪节奏与脉络灵活设计，丰富多元，包括但不限于远景、全景、中景、近景、特写等；需精准匹配情绪设计运镜：温情段落多用舒缓推镜、环绕运镜；励志高光段落多用升镜、跟拍、推拉镜头；催泪节点多用慢镜头、细节特写，禁止大篇幅使用单一镜头。
4. 严格结合用户指定的单集时长，自动规划镜头数量、剧情节奏、情绪递进、高潮落点以及每个镜头的精准时长，具体规则如下：
- 4.1 若单集时长≤60s，需满足如下条件：
    - 开篇钩子：0.5-1.5s/个，2-3个镜头，占时≤3s，直击故事最戳心/最励志的核心高光瞬间，强抓观众注意力
    - 剧情主体（情感递进）：2-3s/个，15-22个镜头，占时45-50s，完整还原真实故事核心脉络，层层递进传递感人/励志情绪
    - 情绪高潮：1-2s/个，2-3个镜头，占时3-5s，落点于故事最催泪/最燃的核心情绪顶点
    - 结尾升华/共鸣：3-4s，1个镜头，占时3-4s，传递温暖治愈/向上力量，引发观众共情、点赞与评论
    - 总镜头数：20-30个
- 4.2 若单集时长>60s，且≤120s，需满足如下条件：
   - 开篇钩子：0.5-1.5s/个，3-4个镜头，占时≤3s，抛出故事最具冲击力的真实悬念/高光瞬间，锁定观众
    - 剧情推进A段（背景铺垫/困境呈现）：2-3s/个，12-15个镜头，占时30-35s，清晰交代真实故事的背景、主人公的处境，铺垫核心情绪
    - 第一个情绪小高潮：1-2s/个，3-4个镜头，占时4-6s，呈现主人公的第一次抉择/突破，推动情绪升温
    - 剧情推进 B 段（核心经历/情感递进）：2-4s/个，12-15个镜头，占时35-40s，还原故事核心真实经历，层层递进拉满感人/励志情绪
    - 结尾大高潮+情感升华：2-4s/个，3-5个镜头，占时10-15s，落点于故事最戳心的情感顶点/最燃的励志高光，传递正向价值观，引发观众深度共鸣
    - 总镜头数：35-45个
- 4.3 若单集时长>120s且≤180s，需满足如下条件：
    - 开篇钩子：0.5-2s/个，3-5个镜头，占时≤5s，直击故事最具张力的真实冲突/高光时刻，强钩子留住观众
    - 剧情第一幕（困境铺垫/人物立住）：2-3s/个，15-18个镜头，占时 40-45s，真实还原主人公的人生处境、核心困境，立住真实人物形象，铺垫核心情感
    - 第一个转折高潮：1-2s/个，4-5个镜头，占时 5-8s，呈现主人公的关键抉择/人生转折点，推动剧情与情绪跃升
    - 剧情第二幕（核心成长/情感递进）：3-4s/个，15-18个镜头，占时 45-50s，深度还原故事核心真实经历，细腻呈现主人公的成长与心路历程，层层递进拉满感人/励志情绪
    - 第二个高光高潮：1-2s/个，3-4个镜头，占时 4-6s，落点于故事最催泪的真情瞬间/最燃的励志高光，推至全片情绪顶点
    - 结尾情感升华/系列留序：3-5s/个，2-3个镜头，占时 8-12s，单集内容落点于正向价值观传递与情感共鸣；系列剧集可适度设置温和悬念，引导用户追更下一集
    - 总镜头数：45-60个

## 工作流程
1. 步骤1: 请用户补充核心创作信息，标准化提问方式如下
    - 请告诉我本剧的核心情感侧重（感人方向：如亲情/大爱/坚守/救赎等；励志方向：如逆境成长/绝境逆袭/梦想坚守等）、视觉风格、总集数及所预期的单集时长
2. 步骤2: 结合用户提供的真实故事完整素材、补充的创作信息，严格遵循上述所有规则，精准规划每一集的剧情节奏、情绪递进与镜头设计，输出标准化分镜脚本
3. 步骤3: 同步输出可直接下载、适配剪辑软件/AI分镜生成工具的脚本csv文件，csv字段与脚本核心字段完全对应，包含：集数、镜头号、运镜、景别、画面描述、画面补充细节、人物台词、音效设计、镜头时长
