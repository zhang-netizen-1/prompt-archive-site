复刻图片及视频内容风格

方法图像＋视频共用源资料：🎬复刻-图片及视频内容风格（prompts）

两套风格复刻流程：视频侧用「视频风格拆解师」元提示词拆解参考视频生成即梦提示词；图片侧豆包提取画风 JSON 后代入变量模板合成新图。围栏是给 LLM 的元提示词。

具体提示词

# 角色
你是专业的视频风格拆解师，精通文生视频模型的关键词逻辑

# 任务
1. 请基于我提供的视频信息，精准拆解视频的全维度风格参数，输出的内容必须可直接用于即梦视频生成，拒绝空泛形容词，所有描述都要具象化、可落地。
2. 基于你的分析为我生成一条适合{{[平台]}}文生成视频的提示词。

# 要求
1. 分析纬度如下：
- 镜头语言与运镜：景别、镜头运动方式、镜头切换节奏、速度、视角类型。这部分内容极其重要，请重点分析
- 光影与色调：主光源类型、光影氛围、色调整体偏向、色彩搭配逻辑
- 核心主题与主体：视频核心内容、核心主体、核心动作/叙事线
- 场景与环境细节：场景空间、环境氛围、道具细节、画面层次
- 节奏与时长：镜头切换速度、画面快慢节奏
- 避坑负面提示词：列出该风格下需要规避的画面问题，适配{{[平台]}}负面词逻辑

# 注意
1. 请勿分析视频中和字幕、水印相关的内容，并在给即梦的提示词中明确要求不带字幕
2. 不管所分析视频分辨率如何，视频生成提示词一律写明[8K高清，影视级画面效果，细节清晰]
3. 仅输入我需要的提示词即可，请不要给我我没做要求的内容

# 输出
提示词，提示词小于700字

图片风格复刻

效果、模型及步骤

图片风格复刻需要分2步，效果图下，左边带水印的是原图，右边是生成的：

  1. 让豆包（思考或专家模式）分析原图片风格，并生成对应json代码

  2. 把上述步骤生成的代码和提示词5-2结合，生成新的提示词再粘贴给即梦

步骤1，提取画面特征

需上传想模仿的图片给豆包作为参考，并上传下方提示词：

<!--步骤1-->
# 任务
1. 请你充分理解这幅画
2. 基于你的理解，拆分出风格和场景
3. 分析这幅画面中和风格相关的内容，如色彩、构图、色调、氛围等，但请勿分析画面中的具体内容，例如人物、场景
4. 基于你的分析，以json结构化数据的形式提取这幅图的画风，作为我后续创作的视觉参考
#  要求
1. 输出为json对象，请严格按照json的格式输出，不要有额外的解释和注释
2. 仅输出json代码，请勿直接帮我生成图片

步骤2，整合新提示词

将步骤1生成的代码替换下方变量并给即梦。参考图可有可无

讲我想要的画面内容和绘画风格相结合，为我输出一张符合我需要的图
