一、生产架构：先做控制资产，再写视频提示词

flowchart LR
    A[剧情与情绪目标] --> B[角色与场景资产]
    B --> C[空间控制资产]
    C --> D[分镜与表演参数]
    D --> E[分段生成]
    E --> F[连续性验收]

    B --> B1[人脸/服装/光影参考]
    B --> B2[子场景/扩展场景]
    C --> C1[站位图/动线图]
    C --> C2[机位图/全景参考]
    D --> D1[构图与视线]
    D --> D2[台词状态与切镜点]

判断：人物多、空间复杂、动作连续时，继续堆自然语言的边际收益很低；应把关键约束变成图形资产和分镜契约。

最小资产包

  1. 角色资产：主体参考图；身份容易漂移时补高清人脸二视图或三视图。
  2. 场景资产：剧情发生的核心子空间；需要穿越时再由子空间定向扩展到大空间。
  3. 站位资产：人物位置、朝向、视线对象、动作路径。
  4. 机位资产：拍摄方向、景别、镜头移动路径；复杂多人场景可使用全景或导演台参考。
  5. 表演契约：说话状态、声音质感、语速语气、台词停顿、微表情。
  6. 连续性契约：上一镜结束动作、下一镜承接动作、切镜发生点。

二、双人关系：构图不是装饰，而是关系编码

双人画面的核心变量是：位置、大小、距离、角度、朝向。它们共同表达权力关系、情感距离和情绪状态。

构图 主要关系信号 适用场景
前后景高低 仰望、崇拜、卑微、权力差 表白、训话、上下级
正反打俯仰角 强势与弱势、压迫与顺从 对峙、争吵、谈判
对称 平等、对立、僵持 宿命对决、立场冲突
对角线 不稳定、张力、暧昧 拉扯、试探、追逐
框架遮挡 隔离、受困、旁观 孤独、秘密、疏离
肩并肩 亲密、陪伴、共同立场 日常、同行、和解
背对背 决裂、错过、无法沟通 分手、误解、冷战
一坐一站 控制权与等级差 审问、训诫、谈判

三个更稳定的控制轴

  • 距离：亲密不等于必须贴近；有意保留物理距离，反而能制造压抑的情感浓度。
  • 高低：站位、台阶和俯仰角共同决定谁掌控场面。
  • 朝向：正面、侧面、背面及视线回避，可以承担关系变化，不必全靠台词解释。

双人提示词骨架

人物A：画面位置、景别、身体朝向、视线对象、动作
人物B：画面位置、景别、身体朝向、视线对象、动作
关系构图：前后景/正反打/对称/对角线/框架等
镜头：机位高度、景别、运动方向、对焦对象
情绪证据：眼神、呼吸、手部、停顿，而不是只写“悲伤/暧昧”

三、台词情绪：把“有感情地说”拆成四层参数

控制层 回答的问题 示例
说话状态 人物以什么行为说话 低声、冷笑、厉声质问、哽咽、试探、轻叹
声音质感 听起来是什么质地 气声、颤音、干涩、冷淡、清亮、低沉
语气与语速 节奏和力度如何变化 缓慢轻柔、平稳无起伏、急促重咬字、迟疑带停顿
标点与停顿 台词内部如何断句 逗号短停、省略号拉长、破折号转折、问号上扬

写法原则：台词标签必须同时落到可观察的视听证据——口型幅度、咬字、眼神、呼吸和微表情。只写“愤怒地说”仍然不够。

[人物]以[说话状态]说：“[带停顿的台词]”
声音：[音色/气息/颤音]
语速语气：[速度、音量、重音、停顿]
表演：[口型幅度、眼神、眉眼、呼吸、手部动作]

[!warning] 标点影响模型语音表现属于模型行为，不是语言学定律；不同版本必须用同一句台词做 A/B 测试。

四、人物站位：按人数升级控制手段

2—3人：作者当时测试中可用的直接控制方案

以下规则来自作者在当时 Seedance 2.0 环境下的案例测试，适合作为当前模型的复测起点，不代表新的模型版本仍保持相同稳定性。

  • 双人正反打：作者测试中，两张反打参考图都标注站位比只标第一张更稳定。
  • 三人：可先测试三角站位，让画面中间人物承担两侧人物之间的视觉桥梁。
  • 提示词应明确人物朝向和视线对象，不能只写“站在左边/右边”。
  • 作者观察到多张场景图有时会触发模型自行重组空间；当前模型应从少量参考图起步，通过 A/B 测试逐步增加。

既有完整案例见：🎬视频-人物站位2人、3人、多人。

4人及以上：不要把全员精准同框当默认方案

作者在当时版本上的测试显示，人数增加后，位置、朝向和身份会同时失稳。更可靠的降级路线是：

  1. 先建立多人全景，作为空间关系母版。
  2. 主要表演拆成单人或双人镜头。
  3. 用屏幕外视线、声音和动作制造其他角色仍在场的空间感。
  4. 用旋转、横移或视线跟随把下一人物带入镜头。
  5. 群体全景只承担空间交代，不承担复杂表演。

[!warning] “2—3人较稳、4人以上困难”是特定模型版本的经验边界，不是永久上限。新模型应重新做 2/3/4/5 人阶梯测试。

站位图最少要编码什么

字段 必须说明
身份 人物名称或稳定代号
位置 左/中/右、前/中/后景、画面占比
朝向 面向镜头、侧身、背对镜头、面向谁
视线 看向人物、物体或画框外方向
姿态 站、坐、跪、蹲及身体重心
动线 起点、终点、经过区域、禁止穿越区域
排除 站位框、人偶、球体、线条不出现在成片中

同类角色同时出现时，用明显不同的服装主色和轮廓区分身份，避免只靠性别或发型。

五、导演台与720°全景：它是空间参考，不是真3D

能解决什么

  • 在全景参考中摆放人偶，形成角色站位母版。
  • 切换机位，预估不同视角下的景别和人物空间关系。
  • 先生成多人全景，再截图给双人/单人分镜提供同视角参考。

不能解决什么

720°全景仍然是球面投影，不是真正可计算遮挡、深度和碰撞的3D场景。因此：

  • 室外、遮挡少、站位不要求厘米级精确时更适合。
  • 室内围坐、桌椅沙发遮挡、多层前后关系时难度明显升高。
  • 室内可先做俯视布局，再生成全景和机位参考。
  • 不同镜头仍要准备与拍摄视角一致的场景图。

六、场景穿越：从剧情子空间向外扩，不要先造空洞大场景

当人物从卧室到客厅、包间到大厅等连续空间移动时，先解决剧情发生处，再扩展空间。

核心子空间 → 按剧情定向扩图 → 大空间母版 → 分段生成 → 动线衔接

执行规则

  1. 先生成发生细节表演的子空间，并锁定门、窗、楼梯等连接结构。
  2. 以子空间为不变锚点向外扩图；新增元素必须服务后续剧情和动线。
  3. 大场景穿越分段生成，不要求一条视频同时完成交流、起身、下楼、入厅等全部动作。
  4. 平面正视图容易表达左右关系，难表达前后遮挡；复杂走位用线稿、彩色动线和禁止穿越区补足。
  5. 每段末尾保留可被下一段承接的姿态、朝向和运动方向。

七、多动作衔接：切镜点放在动作中间

连续动作

同一地点切换景别时，避免在人物完全静止后切镜。让同一个动作跨越切点：

镜头A：动作启动 → 动作进行中切镜 → 镜头B：承接同一动作并完成

运动中的视觉变化会掩盖景别跳变；静态到静态的硬切更容易产生停顿感。

大空间移动

不必完整展示人物从起点走到终点。提取能传递情绪的动作证据：

  • 雀跃：提裙摆、急促脚步、转身、冲入画面。
  • 悲伤：伸手、手臂垂落、身体失去支撑、倒下。
  • 冲突：抬手、拦截、接触、反作用、后退。

快节奏段落先按情绪拆动作，再为动作、运镜和反应分别分配时长。原资料建议单动作控制在约1秒内，但这是节奏参考，不是固定规范。

八、氛围与真人质感：把身份、光影和材质分开控制

女频氛围三层

  1. 角色光：为剧情不同阶段设计角色主光、侧逆光、轮廓光和发丝光。
  2. 场景光：场景图先有明确、统一的光源方向，再做人物融合。
  3. 空间层次：用前景遮挡、后景信息和浅景深建立层次；环境服务人物，不与人物争夺视觉中心。

作者提出“人物占竖屏约70%、环境约30%”，应理解为构图启发而非硬比例。

真人质感控制

  • 将身份资产与风格质感拆开：人脸多视图负责身份，材质和摄影词负责皮肤与影像风格。
  • 高清脸部二视图/三视图可能比“左侧大脸+右侧全身三视图”的复合图更利于锁定五官。
  • “真人肤质+3D建模类词汇混搭”是作者的工具实验，尚未在本 Wiki 复验，不作为稳定配方。

九、失败诊断矩阵

失败现象 优先检查 修正方向
人物左右位置漂移 是否有站位图、两张反打图是否都标注 补全站位与朝向，不继续堆形容词
人物身份混淆 同类角色服装/轮廓是否过近 拉开主色、发型和轮廓差异
多人同框崩坏 是否让4人以上同时表演 降级为全景交代+单/双人分镜
空间穿模 平面图是否缺前后关系 增加俯视图、动线、遮挡和禁止区
反打背景穿帮 是否只有单一正视场景 生成与反打机位一致的场景参考
台词无情绪 是否只有情绪形容词 补说话状态、声音、语速、停顿和表演证据
切镜卡顿 是否在动作停止后换景别 把切点移动到动作中段并承接同一动作
氛围统一但人物塑料 身份与质感是否绑在一张复杂参考图 拆分人脸身份资产和摄影材质控制

十、验收清单

  • 每个镜头能说清人物位置、朝向和视线对象。
  • 反打镜头拥有各自拍摄方向对应的站位/场景参考。
  • 4人以上场景已决定是精准同框还是空间影射，未默认强求全员表演。
  • 场景穿越的门、楼梯、走廊等连接结构在子空间与大空间中一致。
  • 台词情绪落到了声音、节奏、口型或微表情，不只是抽象情绪词。
  • 连续动作的切镜点位于动作中段，下一镜承接同一动作。
  • 光源方向一致，前景/后景没有抢夺人物视觉中心。
  • 新模型上线后重新验证人数上限、标点表现和参考图数量，不沿用旧经验当事实。
