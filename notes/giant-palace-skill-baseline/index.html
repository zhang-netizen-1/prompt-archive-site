巨物天宫中式美学｜Skill 使用与优化基线

图像玩法图像＋视频共用源资料：👀图片-巨物天宫中式美学-Skill使用与优化基线（prompts）

第三方图像 Skill「巨物天宫中式美学」的使用与优化基线：适用边界、最小输入模板、核心视觉协议与测试记录。上游作者与许可证未声明，公开再分发前需确认。

一句话定位：把用户的一句话场景编译成「无需参考图即可识别为巨物天宫中式美学」的提示词，同时输出 ImageGen 与 Midjourney 8.2 双版本。

关联：👀图片-鎏金水墨幻想-Skill使用与优化基线

适用与不适用

  • 适用：无需参考图即可识别为巨物天宫中式美学；把一句话场景编译为对应提示词；用户明确要求直接生图。
  • 不适用：与巨物天宫/中式仙宫无关的审美；普通产品棚拍；视频运动提示词。

始终保留用户明确给出的人物、数量、动作、物件、地点、时间和情绪，不套用固定模板。

最小输入模板

<一句话场景>：天气/时段 + 地点（天宫/宫殿/云海巨构） + 人物数量与描述 + 动作 + 关键物件 + 情绪/光线意图 + 画幅（默认 16:9）

示例：雨后黄昏，天宫长廊，一名青衣女子抱琴走向远处；16:9。

核心视觉协议

  • 主风格：白玉金阙，辅以云海孤城的留白。
  • 人物尺度分层：纯景观/独行者高度约占画面 1%–5%，承担尺度与情绪锚点；群体活动约占 8%–15%，保证动作可辨；近景人物叙事可更大，但须至少保留巨柱、月门、穹顶、云瀑或超长中轴等一种巨物参照。
  • 活动场景道具关系：涉及喝茶、奏乐、议事、宴饮、阅读、祭礼时，保证动作可读且道具关系正确；「一群」默认 5–7 人，避免无意义人群复制。
  • 画幅：横向电影定场镜头，默认 16:9。
  • 光线：清晨或日落低角度金光，阴影保持青灰冷调。
  • 色彩：象牙白、朱砂红、古金、矿物青绿、雾蓝；避免霓虹和高饱和杂色。
  • 构图：环境主导——前景框景、中景人物与活动、远景云海或巨构，层次清楚。
  • 人物：使用原创、非特定真人的古装人物，默认背面或侧后方，不生成名人肖像。
  • 文本：画面内无文字、标志、水印、字幕或界面元素，除非用户明确要求。

输出结构

  1. 画面设计：不超过 4 行中文，说明主风格、构图、人物尺度与光线。
  2. ImageGen Prompt：一段可直接使用的自然语言提示词，默认中文。
  3. Midjourney 8.2 Prompt：一段可直接粘贴的英文提示词，严格以 --v 8.2 结束。
  4. 可调选项：最多 3 项，如夜景、竖版、冷色。

推荐调用方式

  • 自然语言自动路由：当用户涉及巨物天宫/中式仙宫场景提示词或直接生图时自动触发。
  • 未触发时手动调用：/skill giant-celestial-palace-prompts

已知边界

  • 当前安装版只支持 Midjourney V8.2；其他版本不在校验契约内。未来若恢复多版本输出，必须同步修改正文、references、validator 和回归夹具。
  • 原包 description 499 字符，超过新 Skill 60 字符路由预算；安装版已压缩为 47 字符，天宫正向自动路由与现代产品棚拍反向边界均已实跑，更多近义表达仍需积累。
  • 作者与许可证未声明，来源追踪依赖 source URL 与 source SHA-256；对外再分发前需单独确认授权。
  • 校验器可验证章节、参数、URL、占位符与少量关键词，不能证明人物和道具关系、建筑结构、巨构尺度或最终画面质量。
  • Midjourney V8.2 官方状态已确认（2026-07-24 起为默认版本），本 Skill 主输出固定使用 V8.2。
