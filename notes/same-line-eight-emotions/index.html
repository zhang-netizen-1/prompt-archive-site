一、这组提示词真正值得保留的设计

这不是八条互不相关的情绪文案，而是一组控制变量式表演测试：

  • 固定角色、造型、场景、机位、构图和台词；
  • 统一使用「走开啊」作为语言刺激；
  • 只改变表情链、视线链、身体调度、声线和声音余波；
  • 用相同输入比较模型能否生成八种可区分的情绪表演。

因此，核心不是给情绪堆形容词，而是把情绪编译成一条可执行的表演链：

情绪表现 = 初始状态
        + 外部触发
        + 视线变化
        + 面部肌肉变化
        + 手部与身体调度
        + 呼吸和声线
        + 高潮动作
        + 结束姿态

同一句「走开啊」之所以能产生不同含义，靠的不是文字本身，而是动作、声音与时间关系。

二、八组内容整理

1. 欢喜

情绪曲线

安静凝视 → 意识到正在被拍 → 嗔而不怒 → 压住笑意
→ 轻声说出台词 → 转身回避 → 偷瞟确认 → 笑意彻底露出 → 余笑收束

可见表演要点

  • 眼睛轻轻睁大，眉梢上挑，但眉头不皱；
  • 视线短暂滑向斜下方，再快速回到镜头；
  • 眨眼、嘴角上翘和抿笑同时发生；
  • 轻偏头、整理头发，说出台词时眼角弯起；
  • 台词后立刻抿嘴压笑，再转身半背对镜头；
  • 余光重新靠近镜头，一接触镜头就立即弹开；
  • 最后笑意完整出现，再逐渐收小并垂下眼帘。

声线与声音

  • 声线清亮、柔糯、带笑腔；
  • 音量轻，尾音上扬；
  • 发饰碰撞、衣袖摩擦和环境底噪参与动作确认。

2. 娇俏

情绪曲线

故意板脸 → 嘟嘴与假装生气 → 轻推镜头 → 娇声说出台词
→ 扭头不理 → 眼睛先偷看回来 → 压笑失败 → 再次嘟嘴收尾

可见表演要点

  • 眉梢轻挑，嘴唇抿起，脸颊轻微鼓起；
  • 眉头轻蹙，但不能形成真正愤怒的深竖纹；
  • 手指朝镜头虚推，手腕轻巧翻转；
  • 转头后下巴抬高，保持假装不理人的姿势；
  • 头不转回来，黑眼球先从眼角移回镜头；
  • 嘴角上翘后迅速压平，苹果肌仍泄露笑意；
  • 半侧脸重新出现，嘟嘴、瞪眼，但眼底带笑。

声线与声音

  • 软糯、略带鼻音，语速轻快；
  • 「走」字短促，「开啊」拖长上扬；
  • 台词后可带一声从鼻腔漏出的轻哼。

3. 妩媚

情绪曲线

安静锁定镜头 → 侧头抬眼 → 嘴角先起 → 气声台词
→ 手腕向外挥 → 身体转开但眼神不离开 → 整理碎发
→ 慢眨眼 → 笑意走到眼底 → 凝视定格

可见表演要点

  • 头部轻侧，下巴微收，从眼睫下方抬眼看镜头；
  • 单侧嘴角先勾起，唇部保持湿润高光；
  • 说话时气息先出，声音后到；
  • 两指向镜头外侧轻挥，手腕柔软翻出，指尖在动作末端轻勾；
  • 头部转开后，眼睛仍从眼角斜向镜头；
  • 手指将碎发绕到耳后，动作沿下颌附近收束；
  • 使用一次慢眨眼，随后嘴角与眼角同时进入笑态。

声线与声音

  • 软糯、娇媚、气声偏重；
  • 咬字慢，尾音拖长并微微上挑；
  • 发饰细响和含笑鼻息作为听觉细节。

4. 失望

情绪曲线

深吸气维持平静 → 眼眶出现水光 → 视线短暂逃开
→ 强装不在乎 → 平静说出台词但尾音发颤
→ 转开脸 → 勉强扯出半个笑 → 水光重新聚集 → 肩膀彻底落下

可见表演要点

  • 胸口缓慢起伏，肩膀随呼吸下沉；
  • 下眼睑泛红，眨眼把湿意压回去；
  • 视线滑开后重新拉回，嘴角短暂下坠；
  • 下巴略微抬起，强行维持平静；
  • 台词后转开脸，喉头滚动一次；
  • 单侧嘴角向上扯出不完整的弧度，眼睛不参与笑；
  • 泪水聚到睑缘但不落下，最终只留半张侧脸。

声线与声音

  • 声线年轻、清冷、刻意放轻放平；
  • 尾音在最后一个字上出现轻微颤抖；
  • 呼吸保持克制，檐铃、风声和饰品轻响强化空落感。

5. 委屈

情绪曲线

眼底有水光 → 回避镜头 → 下唇前突、眉头内侧上提
→ 听见画外声音 → 抬手想打但停住 → 攥紧袖口
→ 吸气卡住 → 由下向上看镜头 → 哽着说出台词
→ 转开脸 → 擦泪或强行截住抽气 → 倔强停住

可见表演要点

  • 视线先躲开并下垂，下唇轻微前突；
  • 眉头内侧上提，形成浅八字，而不是整条眉毛同时紧皱；
  • 水光增加，但前段不立刻落泪；
  • 手抬起后迟疑，不完成击打动作，改为攥住自己的袖口；
  • 肩膀向内收，头部小幅后让；
  • 呼吸吸到一半停住，再从鼻腔短促泄出；
  • 视线由下向上抬回镜头，停留后才说出台词；
  • 台词后立即抿唇，阻止抽气完全变成哭声。

声线与声音

  • 声音发哑，带压不住的哭腔；
  • 字头先抖一下，音量很轻，不是喊叫；
  • 袖口摩擦、吞咽、鼻息和压抑呼吸共同完成表演。

6. 愤怒

情绪曲线

目光变硬 → 眉心收拢 → 下颌与两腮绷紧
→ 呼吸加重 → 吸气压在喉咙里 → 身体前压
→ 短促、咬实地说出台词 → 重呼吸余波

可见表演要点

  • 视线从普通注视变为固定钉住镜头；
  • 眉心逐步收拢，竖纹由浅到深；
  • 下颌收紧、双唇压直，唇色因用力变浅；
  • 鼻翼张合和胸口起伏先于台词出现；
  • 喉头滚动，但暂不出声，形成爆发前的蓄力；
  • 爆发时身体向镜头方向前压，动作幅度明显增大；
  • 台词结束后不立刻恢复平静，以重呼吸保留余波。

声线与声音

  • 低音量但高压力，不靠大喊表达愤怒；
  • 「走」字咬重，三个字之间几乎没有空隙；
  • 尾音短而硬，无哭腔；
  • 爆发前的吸气、珠串碰撞和台词后的鼻腔重呼吸是关键声画节点。

7. 崩溃

情绪曲线（当前截图可见部分）

安静站立 → 听见画外声音 → 瞳孔收缩、快速眨眼
→ 摇头确认自己没有听错 → 手抬起后停在半空
→ 再次听见声音 → 身体后退 → 眼眶迅速蓄水 → 动作开始失去控制

可见表演要点

  • 外部刺激出现后，眼睛和头部先反应，身体稍后才后退；
  • 想整理碎发的手在半空停住，用「未完成动作」表现认知断裂；
  • 第二次刺激使肩膀收缩、身体后退，发饰被惯性带动；
  • 头部连续摇动、下唇前突、眼眶快速蓄水；
  • 崩溃不是单一哭脸，而是动作秩序由可控变为失控。

声线与声音

  • 截图设定为同一句台词先冲高、被哭腔劈开，再塌成更破碎的重复；
  • 吸气在喉头中断，呼气混入呜咽；
  • 声音曲线承担「控制失效」的证据。

8. 心死

情绪曲线（当前截图可见部分）

彻底失焦 → 泪水自行滚落但面部不反应
→ 以极小口型、扁平气声说出台词
→ 保持微张唇与悬空视线 → 第二颗泪落下
→ 极慢偏头 → 视线晚于头部撤离镜头

可见表演要点

  • 眼睛穿过镜头，不把焦点落在拍摄者身上；
  • 泪珠滚落时，嘴角、下巴和眉头不随之抽动；
  • 说话口型很小，喉头起伏不明显；
  • 台词后保持嘴唇微张，不做情绪性收口；
  • 呼吸浅慢，胸口起伏接近不可见；
  • 转头速度极慢，视线撤离略晚于头部动作，表现关系被切断。

声线与声音

  • 以气声为主，扁平、干涩、没有明显起伏；
  • 无哭腔，尾音直接散在气息中；
  • 与「失望」「委屈」的根本差异是：不再试图让对方理解，也不再保留反应强度。

四、提示词撰写方法

1. 先固定实验条件，再改变情绪变量

这组案例最重要的方法是：不要同时改变角色、场景、镜头、台词和情绪。

如果每条提示词都更换场景和动作，就无法判断结果差异来自情绪调度，还是来自其他视觉变量。固定条件后，同一句台词才会成为情绪表演的测试基准。

可固定的内容：

  • 同一角色与参考图；
  • 同一服装、发型、发饰；
  • 同一场景与光线；
  • 同一机位、景别和焦点；
  • 同一句台词；
  • 同一总时长与画幅；
  • 同一禁止项。

只改变：

  • 表情起点和终点；
  • 视线移动方式；
  • 头、肩、手和身体动作；
  • 呼吸节奏；
  • 语速、音量、音色和尾音；
  • 台词出现时点；
  • 动作之后的余波。

2. 先写机位，再写表演

这组提示词通常先明确：

固定机位 / 近景或胸上特写 / 人物居中 / 镜头与眼睛齐平
单场景 / 不切镜 / 浅景深 / 焦点锁定双眼

这一步把空间问题冻结，模型才可以把生成能力集中在微表情和身体表演上。

固定镜头不是所有视频提示词的通用答案，但对同一人物、同一台词、情绪对比实验非常有效。

2.1 真正的撰写方式：每句话都是一条执行指令

此前最容易犯的错误，不是字段缺失，而是句子仍按剧情文案的方式组织：先讲人物感受，再用动作辅助说明。这种写法即使塞进时间轴，也只是“带时间码的小说”。

生成提示词应反过来：

先确定这句话由谁执行，再写执行什么、从哪里到哪里、怎么结束。

句子的主语只能来自五类对象

主语 负责描述什么 示例
摄影机 / 镜头 机位、朝向、景别、构图、运动、焦点、起落幅 摄影机位于人物正前方，与双眼齐平；镜头固定，焦点锁定双眼
人物 / 身体部位 站位、朝向、视线、表情、肢体动作、呼吸 右手从画面下缘抬至胸前，五指收拢攥住袖口
道具 / 环境元素 位置、移动路径、物理反应、进入或退出画面 珍珠流苏随转头向右摆动一次，再自然回落
声音 声源、时点、强弱、持续时间、与动作的同步关系 手指攥紧袖口时出现一次短促布料摩擦声
约束 需要保持不变或禁止出现的内容 全段无第二人入画；除指定台词外不产生其他说话口型

如果一句话的主语是“情绪”“氛围”“故事”“观众”“她的内心”“这一刻”，通常已经偏离生成语言。

单句的标准语序

时间 → 执行主体 → 起点/初始状态 → 动作路径
→ 速度与幅度 → 终点/停留状态 → 一个同步反应

例如：

4.2—5.2 秒，右手从身体右侧抬至镜头前方，
手掌朝外，以慢速向外推约半臂距离；
动作末端手腕向外翻转，袖口随动作摆动一次。

这句话明确了：

  • 谁在动：右手；
  • 从哪里开始：身体右侧；
  • 往哪里动：镜头前方并向外；
  • 运动方式：慢速、半臂距离；
  • 如何结束：手腕外翻；
  • 同步发生什么：袖口摆动。

不要改写成：

她娇嗔地挥手赶人，仿佛舍不得对方真的离开。

后者只是在解释动作是什么意思。

摄影机运动与人物运动分开写

不要用“画面跟着她”“镜头表现她的失望”“镜头充满压迫感”这类主语与机制都不明确的句子。

摄影机：位于哪里，朝哪里拍，是否移动，如何移动。
人物：位于哪里，朝哪里，身体哪个部位如何运动。

错误：

镜头跟着她失望地转过身去。

正确：

摄影机保持固定，不跟随人物转动。
她的头先向画面右侧转动，肩膀随后跟转；
结束时只留左侧脸入画，视线落在画外右侧。

一句话只承担一个主动作

推荐结构：

一个主动作 + 一个由主动作引发的同步反应

例如：

她迅速转头看向画面右侧；两侧流苏因惯性向左摆动。

不要在同一句中同时加入：转头、眨眼、抿嘴、抬手、说台词、流泪、身体后退。动作越多，模型越可能随机丢失或重排顺序。

使用物理动词，不使用解释动词

优先使用：

位于、朝向、抬起、放下、转向、移开、靠近、后退、停住、
进入画面、退出画面、抿紧、张开、收拢、攥住、松开、
上升、下沉、横移、前推、拉远、跟随、锁焦、失焦、
响起、减弱、停止、持续。

谨慎或删除：

意识到、想起、决定、试图、觉得、等待、确认、在意、
仿佛、像是、似乎、意味着、象征、体现、表达、透露、
让观众感到、营造一种、带着某种感觉。

这些词不是绝对不能出现在创作说明中，而是不能代替正式提示词中的镜头事实。

情绪词只能作为校验标签，不能承担动作

可以在规划层写：

本拍目标：委屈达到最高点。

但生成正文必须写成：

眉头内侧上提，下唇向前突起；
视线从地面缓慢抬回镜头，停留 0.8 秒；
吸气在喉头停住，再从鼻腔短促泄出。

“委屈”只是对这一组动作的命名，不是可以被摄影机拍到的东西。

形容词必须绑定可见载体

错误：

她露出破碎、倔强又令人心疼的神情。

正确：

眼眶泛红，泪水停在下睑缘；
嘴唇保持抿紧，下巴轻微发抖；
视线持续正对镜头，不低头、不移开。

“破碎”“倔强”只有在眼睛、嘴部、头部或身体上出现可见证据时才成立。

速度、幅度和终点缺一不可

仅写“转头”“抬手”“向前飞”仍然过于宽泛。至少补足：

速度：缓慢 / 匀速 / 快速 / 突然停止
幅度：小幅 / 半侧身 / 从胸前到镜头前 / 直到完全出画
终点：停在哪里 / 朝向哪里 / 保持多久

例如：

鞋尖在檐边点地，机位先下沉再快速上升；
屋檐向画面后下方退出，剑从右手位置滑至画面下方中央；
双脚落在剑身后，镜头沿太阳方向向前加速，直至云层从画面两侧高速后掠。

而不是：

他带着畅快的感觉，御剑向光激射而去。

正式提示词的五类句子

最终生成稿中的句子应能够被标注为以下一种：

[C] Camera：摄影机与成像
[P] Performance：人物调度与表演
[O] Object：道具和环境运动
[S] Sound：声音事件
[R] Restriction：连续性与禁止项

交付前逐句标记。如果一句话无法归入 C / P / O / S / R，通常就是解释、抒情、故事转述或废话，应从生成正文删除。

生成正文不回答“为什么”

创作说明回答：为什么这样设计。
分镜设计回答：这一镜承担什么叙事功能。
生成提示词回答：摄影机、人物、道具和声音具体怎么动。

三层不能混写。提示词不负责证明设计合理，也不负责向读者解释情绪。

3. 把情绪拆成身体事件

「她很委屈」「她非常愤怒」都不是可执行调度。需要拆成模型能看见或听见的事件：

委屈
= 视线下垂
+ 眉头内侧上提
+ 下唇前突
+ 吸气中断
+ 抬手后停住
+ 手指攥紧袖口
+ 由下向上重新看镜头

愤怒
= 视线钉住镜头
+ 眉心收拢
+ 下颌绷紧
+ 鼻翼张合
+ 胸口起伏增大
+ 身体前压
+ 台词短促咬实

4. 时间轴不是分段标题，而是动作因果链

有效的时间轴满足：

前一拍留下的身体状态，成为后一拍的动作起点。

例如：

看镜头 → 视线逃开 → 重新看回 → 台词出口 → 转开脸

而不是：

委屈 → 悲伤 → 痛苦 → 绝望

后者只有情绪标签，没有动作连续性。

5. 每一拍至少写清五件事

部位 + 起点 + 运动路径 + 速度/幅度 + 终点

例如：

视线从地面缓慢抬回镜头，头部保持不动；
眼睛接触镜头后停留 0.8 秒，再快速眨眼一次。

比「她委屈地抬眼看他」更可执行。

6. 声线要写成参数，不只写情绪名

至少应明确：

  • 音量：轻声、正常、冲高、压低；
  • 音色：清亮、软糯、发哑、干涩；
  • 发声方式：气声、鼻音、胸腔发声、喉头受阻；
  • 语速：短促、平稳、拖长；
  • 重音：哪个字咬重；
  • 尾音：上扬、发颤、突然截断、散在气息里；
  • 台词前后：吸气、吞咽、鼻息、抽噎、重呼吸。

同一句台词的差异可概括为：

欢喜：轻软 + 带笑 + 尾音上扬
娇俏：鼻音 + 轻快 + 尾音拖长
妩媚：气声 + 慢速 + 尾音黏连
失望：轻平 + 克制 + 末字发颤
委屈：发哑 + 哽住 + 字头发抖
愤怒：压低 + 咬实 + 尾音短硬
崩溃：冲高 + 劈裂 + 呼吸破碎
心死：扁平 + 干涩 + 尾音消散

7. 声音设计必须和动作同步

声音不是最后补一句「有环境音」。有效写法会把声音绑定到动作节点：

  • 转头时，发饰发生一次短促碰撞；
  • 攥紧袖口时，出现布料摩擦；
  • 抬头前，先出现吞咽或吸气；
  • 台词后，用鼻息、抽气或重呼吸延续情绪；
  • 动作停止时，饰品余响同步衰减。

声音在这里承担的是动作确认，不是氛围装饰。

8. 必须写结束姿态

微表情视频如果没有明确落幅，模型容易在最后几秒继续随机表演。

结束姿态应明确：

  • 人物最终朝向；
  • 视线落点；
  • 嘴部状态；
  • 手停在哪里；
  • 泪是否落下；
  • 呼吸是否仍在持续；
  • 是否保持定格到视频结束。

五、这组提示词仍存在的专业性问题

1. 镜头事实与剧情解释混在一起

截图里仍可见类似表达：

  • 「这次不是想看，是确认是不是还在拍」；
  • 「这次咽下去的是委屈」；
  • 「她在等他先低头」；
  • 「像收回最后一点在意」。

这些句子能帮助创作者理解意图，但模型无法直接拍摄「想」「确认」「委屈」「等待对方低头」「最后一点在意」。它们应移入导演说明，生成提示词只保留可见动作。

解释性写法 生成期写法
这次不是想看，是确认是不是还在拍 眼睛从侧方转回镜头，停留 0.4 秒；一接触镜头立即移开，连续眨眼两次
这次咽下去的是委屈 喉头明显滚动一次，嘴唇保持闭合；肩膀同时向内收紧
她在等他先低头 视线由地面缓慢抬回镜头，停留 0.8 秒；下唇前突，眉头内侧上提
像收回最后一点在意 头部以慢速向侧方转动，视线晚于头部离开镜头；结束时不再回看

2. 个别时间段动作密度过高

一秒左右同时出现：

  • 眼神变化；
  • 眉毛变化；
  • 嘴部变化；
  • 头部动作；
  • 手部动作；
  • 发饰运动；
  • 台词与呼吸；

模型容易选择性丢失动作，或造成面部不稳定。

更稳妥的分配方式：

一拍只设一个主动作，最多附带一个同步反应。

例如「转头」是主动作，「流苏随惯性摆动」是同步反应；不要再同时加入眨眼、抿嘴、抬手和说台词。

3. 生理细节不能无限细化

瞳孔、眼睑、耳垂、鼻翼、喉头、面颊、下巴和嘴角全部同时精确控制，理论上细腻，实际可能超过模型稳定执行能力。

应优先保留最能区分情绪的三层信号：

  1. 视线与头部方向；
  2. 嘴角、眉头、下颌等主要面部结构；
  3. 呼吸、手部或肩膀中的一个身体信号。

4. 固定镜头适合表演实验，不等于完整导演调度

这组案例的空间关系很简单，所以「固定机位 + 胸上特写」足够。若换成多人、走位或场景互动，仍必须补充：

  • 摄影机具体位于哪里；
  • 从哪个方向拍向哪里；
  • 人物和道具的位置关系；
  • 主体移动路径；
  • 起幅和落幅；
  • 镜头是否跟随、横摇或移动。

不能把微表情案例的固定镜头结构机械套到所有视频。

六、可复用模板

【参考图与连续性】
角色造型、服装、发饰、场景与参考图一致；只继承人物与环境，不继承截图排版、文字或 UI。

【机位与构图】
竖屏；摄影机位于人物正前方，与眼睛齐平；胸上近景；人物居中；单场景，不切镜。

【镜头与光线】
固定机位，仅保留轻微自然呼吸浮动；浅景深；焦点锁定双眼；说明主光方向与背景光斑位置。

【声线】
仅一句台词「……」；说明音量、音色、语速、重音、尾音、台词前吸气和台词后余波。其他时间不做说话口型。

【时间轴】
0.0—1.0 秒：初始姿态与视线落点。
1.0—2.0 秒：外部触发出现；只写可见或可听事件。
2.0—3.2 秒：第一主动作；写清部位、方向、速度、幅度和终点。
3.2—4.5 秒：情绪转折；用视线、面部或身体动作表现。
4.5—5.5 秒：台词；写清口型、发声参数和同步动作。
5.5—7.0 秒：台词后的余波动作。
7.0—8.0 秒：明确结束姿态，保持至结束。

【声音设计】
环境底噪：……
事件声音：按时间点绑定饰品、衣料、脚步、吞咽、呼吸与台词。

【禁止项】
无新增人物；无多余台词与口型；无字幕、文字、UI、水印、贴纸、平台尾页；无随机转场和黑屏。

时间轴句法

[时间段] + [主体部位] + [起点]
→ [方向/路径] + [速度/幅度]
→ [终点与停留]
+ [一个同步反应]

去剧情化检查词

如果正式生成提示词大量出现以下词语，应检查它们是否只是解释：

为了、体现、象征、仿佛、像是、似乎、意识到、想要、决定、觉得、等待、在意、委屈地、悲伤地

这些词并非绝对禁用，但必须能够被后续的可见动作完整替代。

七、使用结论

  1. 这组案例最有价值的不是八个情绪形容词，而是同一句台词的控制变量测试法。
  2. 情绪提示词的基本单位不是形容词，而是按时间发生的身体事件。
  3. 视线、面部、身体和声音需要共同指向同一情绪，但每一拍不能超载。
  4. 剧情解释可以留在导演说明，生成提示词必须改写成机位、方向、路径、幅度、节拍和落点。
  5. 固定机位和单场景能减少空间变量，适合测试微表情；复杂场景仍需恢复完整的镜头与调度语言。
  6. 台词后的余波与最终姿态，往往比台词本身更能区分相近情绪。
