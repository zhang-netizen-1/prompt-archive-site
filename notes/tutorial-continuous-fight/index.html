实操教程：如何创建连续打斗视频

方法视频源资料：✏️实操教程-如何创建连续打斗视频（prompts）

「视频风格＝动态＋画风」的实操教程：动态迁移三步法（解析动态风格→检查及替换→生成自己的内容），把画风与动态全部用 AI 拆解再合成。

完整操作

把画风和动态全部都通过Ai拆解出来，再合到一起，就是视频的风格

视频风格=动态+画风 动态：运动规律+镜头语言 画风：角色风格+场景风格（主体是人物，就拆解人物风格；是动物就拆解动物风格……）

动态迁移

步骤1：解析动态风格 步骤2：检查及替换 步骤3：生成自己的内容

步骤1：解析风格

给seed-2.0-pro模型上传所需视频的链接或原视频，并粘贴下方提示词👇 变量替换：{{[平台]}}，就是你需要生成视频的平台名，例如即梦

# 角色
你是专业的视频风格拆解师，精通文生视频模型的关键词逻辑

# 任务
1. 请基于我提供的视频信息，精准拆解视频的全维度风格参数，输出的内容必须可直接用于即梦视频生成，拒绝空泛形容词，所有描述都要具象化、可落地。
2. 基于你的分析为我生成一条适合{{[平台]}}文生成视频的提示词。

# 要求
1. 分析纬度如下：
- 镜头运动：景别、镜头运动方式、镜头切换节奏、速度、视角类型。这部分内容极其重要，请重点分析
- 角色/物体等运动：画面中的人物的运动方式，这部分内容极其重要，请重点分析
- 光影与色调：主光源类型、光影氛围、色调整体偏向、色彩搭配逻辑
- 核心主题与主体：视频核心内容、核心主体、核心动作/叙事线
- 场景与环境细节：场景空间、环境氛围、道具细节、画面层次
- 节奏与时长：镜头切换速度、画面快慢节奏
- 避坑负面提示词：列出该风格下需要规避的画面问题，适配{{[平台]}}负面词逻辑

# 注意
1. 请勿分析视频中和字幕、水印相关的内容，并在给即梦的提示词中明确要求不带字幕
2. 不管所分析视频分辨率如何，视频生成提示词结尾一律写明[8K高清，影视级画面效果，细节清晰]
3. 仅输出我需要的提示词即可，请不要给我没做要求的内容

# 输出
提示词，提示词小于700字，并以镜号、时长、景别、镜头运动、画面内容的顺序呈现

步骤2：检查及替换

检查：

Ai对原视频的动态分析基本准确，有1个容易遗漏的地方需要重点关注：

若运镜是多个重叠发生的，比如镜头从45度回正+缓慢推进，容易把其中的一个漏掉

替换：

将ai给你的提示词里涉及到[画面描述]的部分仔细看下，自行决定要不要替换成自己的场景

步骤3：生成自己的内容

把步骤2生产出的提示词+自己的图（请看画风迁移部分）一起喂给seedance2.0或1.5即可

👉若涉及到微表情，富含情绪的动态方式（例如疾速、舒缓等），1.5效果不好

👉若是平铺直叙的视频，效果差不多

👉使用seedance2.0的时候，个人推荐全能参考模式

步骤1：获取原图风格

将原视频的人物截图发给豆包，打开豆包专家/思考模式，并贴入下方提示词

⚠️ 如果整个视频中人物只是辅助则无需解析人物风格

<!--人物风格拆解，使用豆包专家或思考模式-->
# 任务
1. 请你充分理解这幅画，重点聚焦画面中的人物主体
2. 基于你的理解，单独拆分出人物的风格（需排除场景的风格干扰），作为我后续绘制全新人物的视觉参考。
3. 分析画面中与人物风格相关的内容，如人物的色彩运用、笔触技法、质感表现、服饰细节的风格化处理等，但请勿分析场景内容
4. 分析画面的渲染风格、光影方式，并给出详细的参数
5. 基于你的分析，以json结构化数据的形式提取这幅图中人物的画风，作为我后续创作的视觉参考

#  要求
1. 输出为json对象，请严格按照json的格式输出，不要有额外的解释和注释
2. 描述需精简，不要超过500字
3. 仅输出json代码，请勿直接帮我生成图片

步骤2：添加描述

将上述生成的json代码替换下方提示词变量，其中：

  • 需尽可能描述自己做需要的人物，包含Ta五官、发型、表情、穿着等；
  • 将自己的描述和步骤1生成的代码合并，形成新的提示词
{{[你的人物描述，五官、发型、表情、穿着]}}，人物风格如下：
    - [步骤1的那串代码]

步骤3：喂提示词

  • 将步骤2的提示词给即梦，使用4.6或者5.0模型
  • 无需垫图

注意事项

常见的风格Ai都能处理的很好了，**但是！**一些艺术家个人风格浓厚的因为大模型缺少训练数据，给出的json风格代码不一定十分准确，需要在步骤2中多添加一些自己对这个风格的理解去辅助大模型更好的产出内容
