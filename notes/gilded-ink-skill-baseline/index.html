鎏金水墨幻想｜Skill 使用与优化基线

图像玩法图像＋视频共用源资料：👀图片-鎏金水墨幻想-Skill使用与优化基线（prompts）

第三方图像 Skill「鎏金水墨幻想」的使用与优化基线：任意主体套用鎏金水墨风格，含最小输入模板与视觉协议。上游作者与许可证未声明，公开再分发前需确认。

一句话定位：把用户给出的「任意主体」编译为稳定、可变化的鎏金水墨幻想提示词，风格锁定材质、光线、空间与色彩，不锁定主体身份、形态或眼睛状态。

关联：👀图片-巨物天宫中式美学-Skill使用与优化基线

适用与不适用

  • 适用：人物、动物、建筑、器物、景观等任意主体，均可套用此风格；保留用户指定的主体、姿态与眼睛状态。
  • 不适用：普通黄金产品摄影；通用奢侈品品牌视觉；视频运动提示词。

风格通过表面、光线与空间生效，不通过替换主体生效；用户没有指定人物时，不擅自添加人物。

最小输入模板

<主体>：人物/动物/建筑/器物/景观 + 典型形态 + 数量 + 动作或状态 + 关键部件 + 环境 + 画幅（默认叙事 16:9，单体立像 3:4）

示例：月下女子浅水轻舞，睁眼侧望，半束半披，发饰不能遮脸，服装内中外三层；3:4。

核心视觉协议

  • 主体自由：人物、群像、动物、神兽、植物、建筑、山水、器物、产品、抽象形态或无人空景均可；不因样本曾出现神女而自动加入女性、闭眼、金冠、花钿、月牙、凤凰、古装或人脸。
  • 三类金色材料边界（不得混成一种不透明金色物质）：实心花丝金属——不透明、硬边，只用于冠饰、器物、甲片、建筑构件等确需金属结构处；透明琥珀金液/玻璃——透明、折射、带厚度亮边，背景与主体仍应透过可见；贴附碎金箔——扁平破碎、贴附裂纹/山脊/树根/鳞片/衣褶，由掠光依次显现、不自行发光。另有湿墨/黑漆作为冷色基底。
  • 人物发饰连接与服装三层：发部至少写清发型结构、干湿/松紧、动态方向、发饰种类与固定位置或连接关系，头饰可稀疏/平衡/仪式化但不都戴巨型金冠；服装至少写清不透明内层、主体丝绸/锦缎层、可选半透明纱层，及金线/碎金箔落点。透明鎏金弧流属空间特效时须与薄纱、水袖、裙摆分开描述。
  • 冷暗负空间：蓝黑或青灰阴影、暖象牙中间调、香槟金高光；至少保留一块冷色或暗色负空间，避免过饱和红金。
  • 光线：一个暖色主光或掠光，极弱冷青补光；高光集中少数局部，不做全屏金黄。
  • 每张图只确定一个主鎏金机制 + 一个辅助机制，不堆满冠饰、金液、金箔、金雨、金雾与金色建筑。
  • 文本：画面内无文字、标志、水印、字幕或界面元素，除非用户明确要求。

输出结构

  1. 画面设计：不超过 4 行中文，说明主体形态锁、主分支、构图、主材料与光线。
  2. ImageGen Prompt：一段可直接使用的中文自然语言提示词。
  3. Midjourney 8.2 Prompt：一段可直接粘贴的英文提示词，严格以 --v 8.2 结束。
  4. 可调选项：最多 3 项，如改变材料机制、画幅或冷暖倾向。

推荐调用方式

  • 自然语言自动路由：当用户描述任意主体并希望套用「鎏金/水墨/金色幻想」风格时自动触发。
  • 未触发时手动调用：/skill gilded-ink-fantasy-prompts

  • 当前安装版只支持 Midjourney V8.2；其他版本不在校验契约内。未来若恢复多版本输出，必须同步修改正文、references、validator 和回归夹具。
  • 原包 description 583 字符，超过新 Skill 60 字符路由预算；安装版已压缩为 50 字符，鎏金人物与黑豹非人物任务均已自动路由，更多主体类别仍需积累。
  • 作者与许可证未声明，来源追踪依赖 source URL 与 source SHA-256；对外再分发前需单独确认授权。
  • 校验器可验证章节、参数、URL、占位符与少量关键词，不能证明主体保真、无人物污染、发饰不穿脸或最终画面质量。
  • Midjourney V8.2 官方状态已确认（2026-07-24 起为默认版本），本 Skill 主输出固定使用 V8.2。
